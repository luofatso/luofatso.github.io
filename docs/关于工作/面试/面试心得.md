# 面试心得

职场老油条的一些面试心得，仅供自己一些所思所得。

## 如何面试

面试是一个很重要的事情，当然你也可以马马虎虎的走个过场；但是作为面试者抑或面试官，需要对得起所经历的时间。

1.  面试前准备
2.  面试中互动交流
3.  面试后评价


## 面试准备

- 根据面试者的简历从中大概发现人才的优势及不足；
- 记录一些不确定的，和想确定的，对一些简历的知识提出疑问；
- 对于相对职业相应的知识点考验；
- 相应知识的扩展循环，或者根据项目抑或公司需求再进行提问；
- 一些项目的拓展询问，如参与内容，比重，难点，解决方案；
- 平时如何学习，在哪里学习；学习的安排；及其自我的安排；

## 面试中

### 进行自我介绍

- 获取个人的语言表达能力，及其职业知识应用储备；工作中履历，工作项目；
- 进行对简历知识的匹配度；进行后面的疑问；

### 人事面

人事一般对于技术都是最后面试；一般代表前面面试已经通过；

- 个人学历，履历，工作年限，工作公司时间；
- 表达能力；合作方式；
- 对什么比较在意；

### 技术面试

技术面试，一般运气要靠大部分的；很多面试的人员，都是在职的技术人员；这里面有相当大的一部分人是第一次面试；还有就是着急离职的人员；这里面两个都有坑；
第一种就是有两个因素，技术互相鄙视，这个在技术行业会伴你基本一生；二就是第一次面试的膨胀，还有就是找个技术强的自己就不好办，差点的以后坑多，老问自己也烦；所以他们基本都会找一个稍微比自己差一点的；离职的也会是，如果负责他会找一个能接得住的，如果是被公司卡久了的，那就不好说了。
其实所有的情况都有好有坏，遇到一个好的技术面试人员是很难得额。
