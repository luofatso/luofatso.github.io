## vscode 常用插件

这里记录一些自己常用的

### 1. Visual Studio Intellicode

这个插件旨在帮助开发人员提供智能的代码完成建议而构建的，并且已预先构建了对多种编程语言的支持。

### 2. GitLens — Git supercharged

它会告诉你最后接触一行代码的人是谁

### 3. ESLint

ESLint就会作为一个静态分析代码的工具来快速发现问题

### 4. Chinese (Simplified) 

汉化Chinese

### 5. Auto Rename Tag

自动重命名配对的 HTML / XML 标签

### 6.Auto Close Tag

自动添加 HTML / XML 关闭标签

### 7. vetur

vue2使用

### 8. volar + TypeScript Vue Plugin (Volar)

vue3开发必备插件，与vetur冲突

### 9.Markdown Preview Enhanced

让你拥有飘逸的 Markdown 写作体验

### 10.Open In Default Browser

一个可以快速打开HTML文件的VSCode插件，直接启动本地服务

### 登录账号同步个人数据

更换设备后再也不用每次挨着去手动安装了，可以快速同步个人设置、插件、片断等
