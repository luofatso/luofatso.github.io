# 纯 css 写三角形-border 方法

## 1.triangle up 上三角形

```
#triangle-up{
  width:0;
  height:0;
  border-left:50px solid transparent;
  border-right:50px solid transparent;
  border-bottom:100px solid black;
}
```

## 2.triangle down 下三角形

```
#triangle-down{
  width：0；
  height：0；
  border-left：50px solid transparent；
  border-right:50px solid transparent;
  border-top:100px solid black;
}
```

## 3.triangle left 左三角形
