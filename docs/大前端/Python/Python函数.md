## python 函数

**函数** 是一组可以被重复调用的代码块，用于执行某个特定任务。函数让你的代码更加模块化、易于重用和维护。

```python
def function_name(parameters):
    # 函数体
    # 执行操作
    return result  # 可选：返回结果
```

> - def：关键字，用来定义函数。
> - function_name：函数的名称，用于调用该函数。
> - parameters：函数的输入参数（可以为空），是传递给函数的数据。
> - return：可选的关键字，返回函数的输出值。如果没有 return，函数默认返回 None。
