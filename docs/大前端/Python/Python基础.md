# python基础

## 布尔值

布尔值可以用and、or和not运算。

and运算是与运算，只有所有都为True，and运算结果才是True：

```
>>> True and True
True
>>> True and False
False
>>> False and False
False
>>> 5 > 3 and 3 > 1
True
```

or运算是或运算，只要其中有一个为True，or运算结果就是True：

```
>>> True or True
True
>>> True or False
True
>>> False or False
False
>>> 5 > 3 or 1 > 3
True
```

not运算是非运算，它是一个单目运算符，把True变成False，False变成True：

```
>>> not True
False
>>> not False
True
>>> not 1 > 2
True
```

## 空值

空值是Python里一个特殊的值，用None表示。None不能理解为0，因为0是有意义的，而None是一个特殊的空值。

此外，Python还提供了列表、字典等多种数据类型，还允许创建自定义数据类型，我们后面会继续讲到。

## 字符串

跟js差不多

### 转义字符

转义字符\可以转义很多字符，比如\n表示换行，\t表示制表符，字符\本身也要转义，所以\\表示的字符就是\：

```python
>>> 'I\'m OK.'
I'm OK.
>>> '\\\n\\'
\\
```

### 格式化输出

| 占位符 | 替换内容     |
| ------ | ------------ |
| %d     | 整数         |
| %f     | 浮点数       |
| %s     | 字符串       |
| %x     | 十六进制整数 |

字符串变量

```python
print('%2d-%02d' % (3, 1))
print('%.2f' % 3.1415926)
```

### format()

另一种格式化字符串的方法是使用字符串的format()方法，它会用传入的参数依次替换字符串内的占位符{0}、{1}……，不过这种方式写起来比%要麻烦得多：

```python
'Hello, {0}, 成绩提升了 {1:.1f}%'.format('小明', 17.125)
'Hello, 小明, 成绩提升了 17.1%'
```

### f-string

最后一种格式化字符串的方法是使用以f开头的字符串，称之为f-string，它和普通字符串不同之处在于，字符串如果包含{xxx}，就会以对应的变量替换：

```python
r = 2.5
s = 3.14 * r ** 2
print(f'The area of a circle with radius {r} is {s:.2f}')
The area of a circle with radius 2.5 is 19.62
```

## list

跟js的array类似，都可以从下标获取数据，可以负数就是从后面开始获取。

### append(x)

往list中追加元素到末尾，类似js数组的push方法。

### extend(iterable)

方法用于将可迭代对象（如列表、元组、字符串等）的元素逐一添加到原始列表的末尾。它与 append() 不同，append() 是将整个对象作为一个元素添加，而 extend() 是逐一展开元素进行添加。

- 合并列表（类似 + 但不创建新列表，修改原列表）。
- 逐个添加其他可迭代对象的元素（如字符串、元组、集合等）。
- 处理批量数据，如拼接多个数据源到列表中。

### insert(i, x)

方法用于在列表的指定索引位置 i 处插入元素 x，并将现有元素向后移动。

- 索引范围：如果 i 过大，元素会插入到末尾；如果 i 过小（如负值超出范围），则插入到开头。
- 性能影响：在中间插入元素会导致后续元素向后移动，影响性能，尤其在大列表中。
- 直接修改列表：insert() 方法不返回新列表，而是直接修改原列表。

### remove(x)

从列表中删除第一个值为 x 的元素。未找到指定元素时，触发 ValueError 异常。

### pop([i])

移除列表中给定位置上的条目，并返回该条目。 如果未指定索引号，则 a.pop() 将移除并返回列表中的最后一个条目。 如果列表为空或索引号在列表索引范围之外则会引发 IndexError。

### clear()

移除列表中的所有项。 类似于 del a[:]。

### count(x)

返回列表中元素 x 出现的次数。

### index(x, start, end)

方法用于查找指定元素 x 在列表中的索引位置，如果元素存在，则返回其索引；如果元素不存在，则抛出 ValueError 异常。

### copy()

返回列表的浅拷贝。 类似于 a[:]。
