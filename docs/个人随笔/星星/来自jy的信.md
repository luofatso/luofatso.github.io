# 来自jy的信

```
亲爱的陌生人：
展信好。
在这个信息爆炸、爱意泛滥的年代，手写信大抵是我能想到的、最绵长的浪漫了。
早之前在书信流通盛行的年代，信就是信，爱就是爱，人攀不过的山，就托付给车马邮件，年月距离从来都不是阻碍，把想念一笔一划的写在纸上，白底黑字，黄纸封口，然后再千里万里的寄到想念的人手里，不光文艺，且足够深刻。
迢迢山水寄来的数行字句，全都是经年累月积攒下来的赤城心意。山水长，岁月长，相思长，总归长不过，书信两行。
我穷困潦倒，我巅峰流离，我无字句，只好把这一路山花风月，浊酒夜雨，一并说与你听。
亲爱的陌生人，我们并不相识，也素未谋面，不管你是男孩、女孩，我都希望你过得很好，希望你幸福，希望你未来可期。
可惜我文笔不好，否则我也会为你写月亮。山海自有归期，风雨自有相遇，意难平终将和解，万事终将如意。
陌生人，我给你写了这封远方的信，希望在这个时代里，能给你增添些珍重情意，祝你七夕快乐。


by. 没有哆啦的A梦
23.8.22
```

曾经我也想仗剑天涯，风花雪夜，写尽人间海海，许我青山未老。后来发现——剑是道具，天涯是地铁终点站，风花雪月是手机壁纸。人间海海，我终究是个俗人。罢了，俗人也有俗人的江湖。

因为翻出曾经过往的记忆，发现也并不全是发霉落尘的篇章，你那抹彩虹的明信片（jy的信）依然爱不释手；岁月也不曾让一切成尘埃。希望你经历人间酸甜苦辣，依然向阳而生、未来可期。

> 2024年，开心的事，在年终总结；不开心的，在年终了结。
> 祝所有男孩：承乾坤之正气，立天地之威仪；自是成竹于胸，所行风雨无惧；前程似锦，平步青云，步步高升，鱼化为龙。
> 祝所有女孩：承天地之灵气，立山水之刚柔；自是天资聪颖，所行花团锦簇；春风得意，满腹经纶，星光熠熠，其华灼灼。
> 祝我把世俗的目光，一裁再裁，祝我鼎沸有留白，祝我在人生海海，尽兴，开怀。
