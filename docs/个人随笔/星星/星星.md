# 入乡随俗

- 观沧海

```
观沧海 --曹操

东临碣石，以观沧海。

水何澹澹，山岛竦峙。

树木丛生，百草丰茂。

秋风萧瑟，洪波涌起。

日月之行，若出其中；

星汉灿烂，若出其里。

幸甚至哉，歌以咏志。
```

- 《增广贤文》其中有四句是“竹篱茅舍风光好，道院僧堂终不如。命里有时终须有，命里无时莫强求“

- 未经他人苦,莫劝他人善

- 道阻且长，行测将至，行而不辍，未来可期。

- 想获取那就货到不变的东西
- 强化，改造
- 简易化，反复做
- 真诚

- 生气，描述自己生气的原因

- 小孩快乐很简单，成人简单很快乐
- 请不要假装努力，结果不会陪你演戏。
- 你只管怀揣希望去努力，静待美好的出现。余生漫长，不必慌张。
- 哪里有那么多烂道理，自己觉得值就继续。
- 等待和拖延是最容易压垮一个人斗志的东西，犹豫不决是你最大的敌人。
- 若有诗书藏于心，岁月从不败美人。
- 本来就不需要所有的人都会了解你，因此你也没必要对全世界解释。
- 每一次眺望，都要怀揣着对未来生活的渴望。
- 生活不是用来妥协的，你退缩的越多，能让你喘息的空间就越有限。
- 外界的声音都是参考，你不开心剧不要参考。
- 世界很大、风景很美、机会很多、人生很短，不要蜷缩在一处阴影中，去吹吹风，晒晒太阳吧。
- 没有太晚的开始，每天都是新的，生活，从不亏待每一个努力向上的人。
- 我们无法挽回昨日，明日的成败却可一搏。
- 不要迷失在别人的评价里，用心倾听自己内心的声音，做好真实的自己。
- 经历与年龄无关，但优秀与努力有关。
- 把自己当作一件艺术品，好好磨，用心去爱。你好看了，世界姐好看。
