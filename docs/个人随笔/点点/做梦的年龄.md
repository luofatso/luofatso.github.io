# 做梦的年龄

33岁，我失业了。

对太多事情已经没有了冲动。也许，这就是年龄赋予我的，他们口中所说的"稳重"。

23岁的时候，我想我不会就这样被生活磨去太多的棱角。那些尖锐的、锋利的、曾经让我觉得自己活着的东西，如今都变得钝了。不是没有了，是懒得再伸出来了。

回想起来，我好歹也是做过梦的年纪。我想你和我应该也一样，开始的梦不会像现在这样——它像一艘偏离航道的船，是好是坏，是不好不坏，带着现在的我，漂在我也说不清方向的这片海上。

我们想象不到未来的自己，但岁月的港口终会与那时的我们不期而遇。我好像能掌控自己，又好像什么也掌控不了。

不是不能不好和自己好好和解。只是，曾经那个爱做梦的少年，回不去了。

既然是做梦，那就带我回到以前吧——回到那个做梦的年纪：看到喜欢的就去争取，想做的事就去做，不喜欢的人和事就不去爱。像做梦一样，不是每次想做的梦，都能梦到自然醒。

之前在某期《交换美好》里，那个美好的她，不知在什么情境下问过这样一个问题：如果你能回到5岁时的自己，带着你后来的所有记忆，你会对那个时候的自己说些什么？

5岁，你应该是一个蹦蹦跳跳、叽叽喳喳不停的小孩了。最重要的是，你才刚刚开始用自己的眼睛和耳朵给这个世界存档。所以此刻我跟你说的许多话、做的许多事，你大概都存不进去。但这是我一生仅此一次的对话，我该对你说些什么呢？

让我先想想你此时的样子。我努力翻找记忆的夹层，但33岁的脑子，已经存不住5岁的画面了。那年我应该刚上幼儿园，喜欢蹲在地上看蚂蚁搬家，下雨天会故意去踩水坑，挨骂了哭两声转头就忘——这些是我后来听大人说的，我自己一件都不记得。

但没关系。如果真的可以，让我带着此刻的全部记忆，穿过二十八年的光阴，走到那个5岁的我面前。我会蹲下来，和他平视，对他说：

你什么都不用记住。因为此时此刻你什么都有。此刻的你不知道什么叫失去，不知道什么叫来不及，不知道二十八年后的这个人是谁。你以为日子就是这样一天一天地过，你以为所有的人都会一直陪着你。你不知道后来会发生什么，那太好了，你不需要知道。

你只要继续当那个踩水坑的小孩，当那个为了一块糖就能笑出声的小孩，当那个哭完了就跑去看蚂蚁的小孩。你什么都不用记住，因为此时此刻就是最好的。比后来所有的好都要好。

此时此刻你就是最快乐的、最幸福的。你就是那个不会知道后来会遇到我的你。此时此刻你就是你，我就是我。

他大概听不懂。他会歪着头看我，觉得这个大人好奇怪。然后他会跑开，继续他的事情。但我把这句话说出去了，它就到了。

梦终会醒，我们终会长大。
雨终会停，我们终会启程。
路终会明，我们终会懂得。
继续前行，向左向右，没有答案。
