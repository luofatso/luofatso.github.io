# 我与文字之间，没有一见钟情

翻寻记忆的时间相册，我找不到那个具体的瞬间——没有哪一页折了角，没有哪个句子像闪电一样劈开过我的夜晚。别人谈起与文字的相遇，总有种宿命般的浪漫：或是某本旧书里夹着的枫叶，或是某个雨天偶然读到的一句诗，从此心门洞开，万马奔腾。

我没有。

我翻开自己的来路，只见一条缓坡，没有悬崖，没有瀑布，连个像样的转弯都没有。小学写日记，憋了半天，写下八个字："今天天气晴，无重要事情。"表哥当时看了后，笑了我好长时间。我不明白笑点在哪，但每次翻到那页，都能听见他当时的笑声，像一颗小石子扔进一口很深的井，回声在里头荡了很久。

后来我还是不会写。中学时读朱自清的《背影》，读到父亲翻过月台去买橘子的那段，全班都安静了。我也安静了，但安静里有一种说不清的动。那是我第一次感觉到，文字有一种能力——它能把一个笨拙的、微胖的、翻越铁轨的背影，变成某种永恒的东西。你合上书，那个背影还在你眼皮底下晃。

但这不是"顿悟"。我没有因此立志成为作家，也没有疯狂地抄写名言警句。和文字之间真正有了一点默契，是在一次不太愉快的经历之后。

那天晚自习，我和前桌因为一道数学题争得不可开交，谁也不服谁。我性子急，为了当场证明自己的做法是对的，顺手从桌上抄起一本书就在空白的地方刷刷地画图、演算、推翻、重来，笔尖戳得纸面沙沙响。推导到最后一步，终于得出了答案，我把书往桌上一拍："你看，我的对吧。"，书从桌上弹起来翻了面，正好落在封面页上。

班长不知什么时候凑过来看热闹，想看看那道题到底谁对谁错。他目光刚好落到封面上，整个人顿了一下，笑容慢慢收了。他伸手把书拿起来，翻了两页，上面全是我那些张牙舞爪的推导过程，半天没说话。

"不好意思啊……"我声音都小了。他愣了一下，冲我轻轻的摆摆手说没事，然后继续写题。教室里又恢复了沙沙的翻书声和笔尖声，但那个"没事"听起来不像是真的没事。放学后我在老篮球场的斜坡上追上了他。我跑过去正想再次致歉，他飞快地用手背抹了一下脸，抬起头来，眼眶还有点泛红的，却挤出一个笑，说："没事，就眼睛进沙子了。"

他明明在哭，却要说是沙子。那是我第一次意识到，人和人之间有些话是不直接说的，而文字——或者说语言——最妙的地方，恰恰在于它可以让一句假话，比真话还要真。它替他藏住了一点什么，也替他透露出了一点什么。那句话笨拙，但不粗糙。

后来的路也平淡。高中读鲁迅，读不懂他字缝里那个"吃人"的世界，但喜欢他写"我家门前有两棵树，一棵是枣树，另一棵也是枣树"。说不出哪里好，但觉得那种重复有一种奇怪的力道，像一个人站在原地，反复确认同一件事。

大学读余华，读到《活着》最后那段，福贵牵着他的老牛，对着田埂上的人说——"做牛耕田，做狗看家，做和尚化缘，做鸡报晓，做女人织布，哪头牛不耕田？这可是自古就有的道理，走呀，走呀。"

一个老人对着一头牛说话，像是在自言自语，又像是在跟整个世界聊天。明明讲的是苦了一辈子的事，口气却像是在说今天天气不错。那种调子让我愣了一下，然后笑出来。原来文字还可以这样活——它不必声嘶力竭，不必字字泣血，它可以轻飘飘地、带着点玩世不恭的口气，把很重的东西托起来。

而这些零零碎碎的阅读和经历，像落在土里的雨，说不准是哪一滴让种子发了芽。我只知道，当我心里有话想说却说不清楚的时候，我会不自觉地坐下来，开始一个字一个字地写。写出来的东西不一定好，但写的过程本身，就有一种把自己理顺了的舒畅。

文字对我而言，从一开始就不是舞台上的聚光灯，而是工具箱里的那把螺丝刀。它不负责照亮我，它负责帮我拧紧那些松动的念头，拆开那些纠结成一团的情绪，再把它们重新组装成一个我能看懂的样子。

我喜欢它，大概就是因为这个。

它不会嫌弃我的笨拙。我写"今天天气晴，无重要事情"，它就老老实实地收下；我后来试着把那些说不出口的东西写下来，它也不催我，就那么等着。它不像人那样需要你证明自己，也不像时间那样不管你愿不愿意都要把你推着往前走。它就在那儿，随时等我坐下来，把脑子里那团乱麻一点点捋直。

偶尔捋到一半，会有一句话自己跳出来，恰恰好地落在那个空位上。那一刻的感觉，像钥匙插进锁孔，咔哒一声，门开了。

那种声音很小，但我听得见。

——这就够了。不需要一见钟情，不需要火花四溅。就只是，在一个普通的傍晚，我坐在桌前，把心里的一团模糊写成了几行能看的字。然后我读了一遍，又读了一遍，觉得：嗯，差不多是我想说的了。

这种时刻多起来，就成了一种喜欢。不浓烈，但持久。像窗台上那盆绿萝，没有花，但一直在长。
