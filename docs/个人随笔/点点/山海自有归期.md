# 山海自有归期

每个人本是山海，却又何故奔赴山海？

我带着疑问出发，试图找到答案。以往总爱结伴同行，这一次，我决定一个人去探索。一个人会走得很快，一群人会走得很远——可人生的路，从来无关快慢，也无关远近。从哪走，走哪去，重要，也不重要。要有意思。可什么才算“有意思”？

就像我在想到底要不要宝宝。说“不要”的那刻，心里忽然空落落的，像失了方向；可若说“要”，我就有方向了吗？哺育、成长、目送、远去——那是什么？是延续。对，是文明的延续。可我也是独立的个体，只有这一次。不是要不要宝宝决定了人生有无意义，意义一直都在，只是每个人有选择的权利，有定义的权益。往左往右，没有对错。方向不同，结果能接受，便是相同。

再热闹的城市，也有冰冷的心；再荒芜的山野，也有炙热的人。在哪里不重要，去哪里也未必重要。不是所有河流都奔向大海，不是所有花都开在春天。有希望，有信念，便是共赴山海。

清澈透明的山海，像孩子滚动的眼睛；嫩绿在风中摇曳，阳光拍打在叶片上，鸟鸣清脆。血液循环，风雨交替，日月更替——万物自有节律。

想了好多好多，准备了好久好久，可真正见到你的那刻，我什么都说不出口。万千思绪，抵不过翻越万水千山后静静地相对。沉默已胜过千言万语。简单、朴素，就像那个没读过书的老母亲，不懂万千道理，给我的爱却胜过千千万万。

那一刻，我好像找到了答案，又好像什么都没得到。

此刻我被强制停下，想不出前进的路。我知道没人能替代我，也帮不了我。思绪万千，多数凌乱不堪。我想出去走走。不是走了就能获得动力，只是暂时按下暂停键。想不到好的活法，就先休息一下。就像记忆中那些不可磨灭的痛苦，终归慢慢变成不再波动我前行的梦魇。

后来你会发现，只要往前走，路永远在脚下，身后亦是走过的路。与其争论每条路的对错，不如承认：每条路都是对的。人生本就是用来体验的，每条路都有不一样的风景。

如果每条路都一个样，风景一样，人物一样，场景一样，那人生还有什么意思？

替我自由，但别忘了你本就自由。有些人只是看着需要自由，有些人却是真的需要。

不需要回答，不需要责问。人生本无答案。

山海有归期，风雨有相逢。你只管走，路会记住你。
