# 离舍

对于爸爸的因病突然离去，不管是我有多多的不舍，还是他有多么的不舍，最后的我们都要舍得。天命既如此，我们亦能如此。

今天是中国传统节日——端午，你可曾还记得;我也不知离世人还知世人事否，但愿还有一个那边的世界，那个不在让你含辛的世界。就似佛教所说的那个西方极乐世界。

依然记得往昔每周周末就算我没有和你联系，你都会和我联系的，亦不说什么节假日一类 。虽说现在也能和他们再次联系，只是那份情感已完全不一样。我是多么的感动曾经有你的每一天。

梦中的你依然健在，却是每次梦都不能弥藏我知的现实。梦中的你是多么的和蔼，是以前我从未感受到的那种一样的亲切。我是有多么的傻，为何当初只有叛逆。

“树欲静风不止，子欲孝而亲不在”，记得刚看到这句话的时候，那还是初中读得一本小说内的，那时还因女主人公失去亲人而感伤，而现如今谁能为我感伤呢。那种痛是谁都不会领会的，就算泪落梦醒那都是幸福的。

“分离是为下次最好的重逢”，我还以为这是最好的借口；却那知我们之间的分离，是不能与之相提并论，不提也罢，免得误会了这华丽的借口，再次被它蛊惑了我那麻痹的心。

离舍，离舍——舍得——舍不得，都要舍得。


    FatsoLuo 
    2014-6-7
