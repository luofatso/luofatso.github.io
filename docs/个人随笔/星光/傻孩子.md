# 傻孩子

傻孩子,一路走到现在很累了吧,能不能别那么傻啊.

记忆里的你一开始是个活泼好动的小孩,喜欢大声说话喜欢笑,然后慢慢开始安静,开始沉默,开始隐藏自己的存在.很累吧?

傻孩子,别太轻易的去相信不熟悉的人, 别自以为你对别人好别人就一定要对你好, 等到受了伤就晚了.别太善良,要懂得保护自己.被人欺负了要勇敢点反抗,不要有太多顾忌而委屈了自己.

傻孩子,以后多看点书,要能说会道,和人 相处不是光倾听就可以,能和你在一起沉默而不觉尴尬的也就那么几个.

傻孩子,以后做事要果断点,要懂得拒绝, 不要谁说什么事都说好,可以,行.别人习惯了就变成了理所当然.要记得,你不是什么无 可替代的人,要懂得尊重自己.别吃力不讨好 .要爱自己多一点.

傻孩子,再幸福的人也有不开心的回忆, 所以过去的就让它过去,痛过就让它痊愈吧. 告诉自己要向前看,频繁的回首来路,只会错 过沿途的风景.

傻孩子,没有人有义务一定要对你好,对你付出不求回报的是父母.所以,要对他们很 孝顺,你长大了,可是他们已经开始变老了.

傻孩子,要记得那些给过你帮助的人,并在有能力的时候给以回报.他们帮你是因为 交情,不帮你也是应该的.要记得感恩.

傻孩子,青春是用来成长的,也是用来怀念的.不是每个人都可以白头到老的,有些人 是用来成长的,有些人只能够怀念.

傻孩子,遇见喜欢的人要大胆一点,太安静了或许就错过了.当没有人爱的时候,要学会自己爱自己.闲暇时跟自己去约会,节日的时候送自己个小礼物或者为自己做桌好菜犒劳下自己.

傻孩子,不论发生什么事,都要记得阳光和微笑.也许某一天会有那么一个人仅因为你的笑容而喜欢你:)

傻孩子,要学会独立自信,不骄不躁,即使一个人也过得很好,游刃有余.

傻孩子,要做个温暖爱笑的孩子.
