# 不小心

对于昨天的过错，我是否应该在清晨，第一束阳光还未升起之前反省？这个问，很值得思考。

我不在年轻，不能再像以徃，那样肆无忌惮的错错错；不能什么都在长，自己的思维却停滞不前；失望的人那就不在是自己肉身，还有自己的灵魂。别让肉身在黑夜中寻找灵魂，那样活着，其实已经死了。

你还在干什么？不想自己就这样平凡一生。

我要的其实很简单，只要自己努力就行；让梦离我再近点就好，我宁愿在半路摔得粉身碎骨，也不死在原点——那个看似真实，实则虚假的摇篮中。

不要被现实的虚假，弄模糊了眼睛，冲昏了头脑；也不要别人欺骗，弄得不开心，去自暴自弃。其实生命很简单，也就是眼睛一睁一闭过去了。不要为生命短暂而苦恼，也只需顺应天时便可。

也就如现实好似无尽的苦海，你若再踏红尘把它当梦虚度，就真可谓是可惜深甚。

其实我们每个人的一生，就如同一天的天气一样，也许你是绵绵细雨，或许你是万里无云，也或许你是狂风暴雨。。。无论你是哪一类，但把每个人组就起来，都还是最美丽的。只有我们这些单调的天气，才能组成四季的完美更替。就如同颜色一样，如若就一种色调，哪多枯燥无味啊；只有五颜六色的完美搭配，才会绘画出雨后天边的那道虹。

在人生的道路上，不要气馁。因为自己就是一道天空的虹——永远灿烂夺目！

    LuoFatso
