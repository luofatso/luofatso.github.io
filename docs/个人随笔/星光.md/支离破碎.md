# 支离破碎

- 1。我想要的平凡，最后万万没有想到竟成了平庸。我是多少次想痛心哭泣，我知道我没有资格——那是属于奋斗过人的权限！
- 2。往日不提，只看今朝；可是我怕那个家伙早已敗给往日，还有何等颜面面对今朝！
- 3。总是埋怨现在的自己，老觉以前自己是多么的好，那以前那个自己呢，又去了哪里？对了，老是说以前；那么以前那个我又是什么样子的呢！那我就应该活在以前呀，怎么就到现在啦呢！真奇怪，我现在都在说现在；按这样说，那我以前也在说当时啊！以前那个我又去了哪里？现在的我到底又该去往哪里？什么时候我才像我自己呢？我又去往了哪里？你又是谁？你以前是谁？你以后又是谁？
- 4。想要就追，无果就放！
- 5。想是一回事，做又是另一回事；做的是不是你想的那样，那就在一念之间。就似白天与黑夜一样，它没有实质上的分界线，就似说的那样，只不过是一念之间！
- 6。错乱，我把现实与梦搞混淆，分不清这是梦，现实我也不能确认！
- 7。不要说你修为很好，内在很美，内涵很有品味；其实别人看见的不就是外表；内在美，就更应该去修饰外在的，去证实自己。虚无缥缈。
- 8。在这繁华热闹的城市，有又谁知道谁内心深处的痛。就算这么近，又能诉说什么！
- 9。这样拼死拼活又是为了什么？男人嘛，早晚都会懂——生活！
- 10。我相信一夜之间的成长，虽然有些青涩，多多少少愿与不愿，蜕变那是疼痛的、难免的。谁的青春又不会有那么一次撕心裂肺。
- 11。混时间，真的会很快，不信回想一下过去。昨天还在眼前。
- 12。只是想要个完整的家，那怕做个庸碌的人，也是幸福的。这颗空洞心，填充补满整个黑夜。
- 13。我相信有真正的爱情，只是现在暂时不爱爱情而已！也许那天我会回心转意，那都是你的恩赐，求你不要收回爱情。
- 14。爱我的人就那么几个，却一个少一个，天何必要残忍，有的比从来没有失去更痛！15。有时想想，我为什么要委曲求全活得这么累。年轻人嘛，累了休息一下就没事了。许多事情都还得亲身经历才会品味出生活，人生嘛，不就这样！
- 16。有时头脑一发热，做出的决策；事后却怎么也不敢承受，不要责怪自己真的太年轻，要怪就说自己不争气！ 

    2014-8-6
