# 朋友

```
拥有你是一件美事
是一件快乐的事
也是一件简单的事
我不刻意地去营造什么挽留什么
没有小心翼翼的算计和维系

曾经在人海中相识、相知
共舞一场
相互聆听的同时
各自又吟唱
然后又汇合一起
如茶、如酒，淡而悠长、久而弥香

也许人的本质是孤独的
但那大堆面目模糊的人群中间
总有那么一两个使心弦会一动
让我们彼此相惜、相望、相嬉的人

我们都不一定合情合理
但我们彼此知心知意
我们也不一定形形不离
但我们一定心心相惜
我们也不一定锦上添花
但我们一定雪中送炭
我们也不一定常联系
但我们能彼此放在心上


因为我们是朋友
寂寞依旧
却不在孤单
不在于天长地久
只在于曾经拥有
朋友，祝快乐、幸福永远


    FatsoLuo
    2011-5-2
```
