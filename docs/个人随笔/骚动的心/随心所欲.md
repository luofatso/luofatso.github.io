# 随心所欲

```
那漂浮的小草
    失了肉骨的孤魂
    暗涌魔王的牵扯呢
    怎能阻挡得了
    呵，魔王的子女哟
    玩弄如此野鬼
    真的会责怪？谁会

救你，谁敢？
    我这漂浮无心呆木头
    妄自菲薄——啊？不敢
    哭泣？于心与你
    孤魂啊！野鬼呢！水草啊！

刺骨，暗涌
    让我受折磨，我
    承认，犯下的错
    不敢看透世人，看不透你

魔王啊？
    水草——要去往何处！
    哭泣，谁都没有
    回家--家的路上
                  
                  
	2014-8-7
```
