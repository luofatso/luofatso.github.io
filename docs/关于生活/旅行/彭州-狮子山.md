# 彭州-狮子山

这期好像也没有什么特别之处，但却是到此为止筛选照片最多的一期，左右割舍都不容易；这也许是以前最接近生活的样子，也是最遥远的熟悉模样...

<LImg :imgs="szs1" width="75" intr="普普通通平平凡凡，却又总是念念不忘" />

吸取多次路上堵车的经验，本次我们出发基本全程高速，所以到达狮子山徒步登上口的时候菜上午十点半；但停车场还是被停满了，我们只有开车往上走了一点，果然上面不远处就有一个停车场。

<LImg :imgs="szs2" width="75" intr="是刻意而随意的安排" />

一开始的路就这种青石台阶路，让我想到上次葛仙山的台阶，会不会如出一辙的套路呢？一上来就先给你开启困难模式，劝退那些左右不坚的人们，留下能真正懂得赏悦它的少年...

<LImg :imgs="szs3" width="75" intr="再好再坏，都需要自己亲自去丈量" />

我们好像很多次出来徒步游玩，都是前一天晚上临时寻找决定的，这样确实很有‘说走就走的’味道，好处就是比较随心所欲，坏处当然也比较明显，就是攻略并不完善，途中可能会遭一些罪等。

<LImg :imgs="szs4" width="75" intr="零星的记忆，燃烧那片荒芜" />

对面就是我们来过多次的海窝子古镇，所以昨晚确定要来这里的时候，让我瞬间唤起了上次的零星记忆；是那次我们去‘阳平竹海’一抹余光，燃烧起了我们这次的狮子山难忘之旅。

<LImg :imgs="szs5" width="75" intr="无迹可循的规律，还是按耐不住" />

来到山上后的路，确实和之前的葛仙山又相像之处，却又毫不相干。是的，这世界总是有千千万万的规律可循，却也又无迹可寻，并不是吗?

<LImg :imgs="szs6" width="75" intr="去听鸟叫，去看彩林，去拥抱自然，去做追风的少年" />

但是不管世界如何的变化，我们还是要保持最开始的模样呀；如果那天你身心俱疲放不下所有的时候，你只需要回归大自然，去听鸟叫，去看彩林，去拥抱自然，去做追风的少年...

<LImg :imgs="szs7" width="75" intr="要去守护内心藏匿的那份宁静，也要去追寻心底深藏的那份炙热" />

有时候我们总会去抱怨是这个世界是怎么了，却从来没有去想想是不是我们自身的问题；以往的岁月车马很慢，书信还很长到处可见；现在虽然依是车水流马，但我们自己的内心却变得更加浮躁了。

<LImg :imgs="szs8" width="75" intr="要去守护内心藏匿的那份宁静，也要去追寻心底深藏的那份炙热" />

放下你的手机，并取下你的耳机；因为大多时候是我们自己，不小心关闭了感知的门；你有多久没有认认真真的去走路——对，是走路！它是很简单，所以我们才会在最简单的事情上，做点其他事情而忽略它...

<LImg :imgs="szs9" width="85" intr="我们忽略了，那些简单的事情" />

那些简单的事情，是我们不曾去留意的生活点滴，我们总是把所有的精力都放在那些——所谓的重要的事情和人身上。却忽略了真正的重要的人和事，人往往都是后知后觉的，愿我们都去在意真正在意我们在意的。

<LImg :imgs="szs10" width="85" intr="人会长大，也终会远去" />

‘年年岁岁花相似，岁岁年年人不同’朋友总会在不经意间，念想起一些有意思的诗句，然后在来一句灵魂的拷问:'为什么人会不同'？是呀，是为什么会不同，我当时是觉得‘人会长大，也终会远去’。

<LImg :imgs="szs11" width="85" intr="童年和故事一样，它门永远都在我们心里不会长大" />

当时觉得这个答案非常完美也比较契机，现在再回想这个答案，却并不令人那么满意；也许人终是会长大，但故事却并不会也跟着一样远去。

<LImg :imgs="szs12" width="85" intr="好好生活，杜绝没必要的粗糠泡面" />

‘花有重开时，人无再少年’希望我们的生活都是多姿多彩的，而并不全是一成不变的手机、新闻、资讯、抖音、短视频...它们并不是全都一无是处，只是太多就有点滥竽充数了，就像粗糠泡面一样。

<LImg :imgs="szs13" width="85" intr="他们都总是如此的乖巧，并表现得楚楚动人" />

‘最理想的生活状态是：吃饭，睡觉，适当思考，绝不争吵。’前几天看到的一句话，我觉得适当思考真的很重要，因为这个世界充斥太多的诱惑，他们总想夺取我们的眼球，然后把我们深陷其中。

<LImg :imgs="szs14" width="85" intr="充斥我们眼球的并不一定是真实的" />

我们以为那些无法自拔的都仅是一些坑，深不见底进去就出不来的坑？甚至也会觉得我们永远不可能种下他们的圈套；其实不然他们挖的也并不一定是一个直直向下的深坑，他们可能是挖一条又滑又长的路。

<LImg :imgs="szs15" width="85" intr="你不是一个人在战斗" />

也许在我们觉得新奇的时候，我们就已经在挖好的道路上一发不可收拾了。因为我们只是一个人在面对，而他们是整个团队设计的‘圈套’。

<LImg :imgs="szs16" width="85" intr="什么时候，才是真正属于自己的时间" />

这也许就是我之所以，一直坚持写一些不痛不痒的东西的原因吧，我并不希望它能给我带来什么，但是却能让我更为平静、从容的去思考一些东西。

<LImg :imgs="szs17" width="85" intr="我们忽略了，那些简单的事情" />

只有我们停下来开始思考的时候，才会发现我们自己的存在的问题；我们需要一些前人的经验，在这个浩瀚无边的人海里走的不至于看起来那么狼狈。

<LImg :imgs="szs18" width="85" intr="读万卷书不如行万里路，行万里路不如阅人无数" />

这一期原本有好多好想分享的东西，但真正提笔扣字的时候才发现，自己又是那么的无知；‘读万卷书不如行万里路，行万里路不如阅人无数’——一直在路上。

<LImg :imgs="szs19" width="85" intr="风景也会随时间变幻，但故事终不会变老" />

在路上不要停下来，人虽会随时间长大，风景也会随时间变幻，但故事终不会褪色，我们的经历也不会变老，五彩斑斓的也不仅仅是彩虹是吧!

<LImg :imgs="szs20" width="85" intr="让一切浮躁与烦恼全部消失，五彩斑斓的也不仅仅是彩虹" />

最后阶段我们的食物和水都消耗完了，还好有酸甜的刺果充斥着味蕾；这一路且行且珍惜，随时保持对生活的赤城和敬畏之心...

::: tip 提示
出行地点：彭州狮子山户外登山健身步道

门票：免费

我们是秋冬时节去行的，一路并没有蚊虫之类的阻碍；春夏植被应该会很茂密，所以春夏出行应该穿长袖避免蚊虫和植被。

狮子山健身徒步线路共有好几条线路，可以根据自身的身体状况选择路线；路况基本都是野路，有大小环线供爱好者选择；大环线也就10多公里，小环线5-6公里左右，徒步时间根据个人状况不定，一天内出行基本没有压力。

山上没有看到供给点，所以提前准备好徒步的供给所需；路上部分路段垃圾比较严重，倡议大家把垃圾打包带下山，提供良好户外环境人人都可爱。
:::
