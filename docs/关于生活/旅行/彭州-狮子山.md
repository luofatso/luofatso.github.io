# 彭州-狮子山

去听鸟叫，去看彩林，去拥抱自然，去做追风少年。

好像这期也没有什么特别之处，但也是由此到目前为止筛选照片最多的一期，左右割舍都不容易；这也许以前最接近生活的样子，也是最遥远的熟悉模样...

<LImg :imgs="szs1" width="75" intr="普普通通平平凡凡，却又总是念念不忘" />

吸取多次路上堵车的经验，本次我们出发基本全程高速，所以到达狮子山徒步登上口的时候菜上午十点半；但停车场还是被停满了，我们只有开车网上走了一点，果然上面不远处就有一个停车场。

<LImg :imgs="szs2" width="75" intr="普普通通平平凡凡，却又总是念念不忘" />

一开始的路就这种青石台阶路，让我想到上次

我们好像很多次出来徒步游玩，都是前一天晚上临时寻找决定的，这样确实很有‘说走就走的’味道，好处就是比较随心所欲，坏处当然也比较明显，就是攻略并不完善，途中可能会遭一些罪等。
