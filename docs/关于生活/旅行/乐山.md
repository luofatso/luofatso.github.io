# 乐山

乐山，你好！

在我很早的愚昧意识里面，乐山就只有大佛可游览一次；其实一个地方的人文景观又岂止自己心里的一二，可能峨眉山的猴子都没有如此肤浅——为自己，行万里！

<LImg :imgs="ls1" width="85" intr="乐山，你好" />

原计划我们准备是去西安游玩的，由于其它原因没有抢到票，但是又不想辜负这个假期，再三思索下我们来乐山啦（差点乐山的票也没买到，小声BB一下——真难）😢！

我们来乐山并不是退而求其次，其实早就在我们的行程安排中，只是日程上来说靠后一点；因为乐山距离成都比较近，所以我们原计划安排是以后的某一个周末，但是也不影响我们提前行程。

<LImg :imgs="ls2" width="85" intr="小豆海棠——豆腐脑" />

我们到乐山也才8点过点，原计划就是安排乐山豆花，听说跟成都的很是不一般；下高铁原计划是打车到嘉兴美食街的，奈何人好像有点多，这样子下去我的早饭岂不是要迟迟赶不上😰;发现路边有好多友好的共享电动自行车，且看距离也还能接受，我们一拍即合直接迎风而行，吹着微凉带朵朵朝霞的风，惬意也别说那番！

别说时间早，但是来吃豆花的人是真的似排队的候鸟，晚了都没有地😯。

<LImg :imgs="ls3" width="85" intr="好刚要在用刀刃上" />

豆花排队的人实在是太多了，所以我们重新安排了其它的，因为如果排队时间过于长，我们想那就失去了我们对它的憧憬；这家的红糖醪糟和馅饼也还挺不错的，打消了媳妇没有让我点炸酱面的怨气，用她的话说叫——好刚要在用刀刃上（吃货的境界）。

<LImg :imgs="ls4" width="85" intr="走不动路的‘绵绵冰’" />

既然说了是要吃喝玩的一天，那就应该有该有的样子啦，谁都不能阻挡我们快乐的脚步，下一周翰园街...

<LImg :imgs="ls5" width="75" intr="好像再述说着什么" />

原计划是在翰园街吃钵钵鸡的，来都来都了怎么能少得了这等美食呢；奈何大家都是这么想的，排队的人是真的难以叙说，步行我们去人民北路吧，总是有更好在向我们招手🤪！

<LImg :imgs="ls6" width="75" intr="好吃，本地人的推荐" />

正不正宗谁说了都不算，只有亲身体验过才有发言权，真的不愧我步行而至；过来时间刚好是吃午饭的时间，但是我们是比较积极的那种；总算没有排队啦，刚好选好坐下，外面就开始了‘候鸟排队计划’。

味道好极了，比前天在锦里买那个味道更正宗——不辣，很鲜香...最重要的是价格还挺合理的，结账之际还另外买了一袋他们的料（总共才70几），悄悄的告诉你下次我还来。
