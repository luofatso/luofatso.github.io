# 大邑-云中屋

特此记录，练车三连：

- [新津-斑竹林](./新津-斑竹林.md)
- [成都-龙泉-紫霞山](./成都-龙泉-紫霞山.md)
- [大邑-云中屋](./大邑-云中屋.md)

这个季节还是比较想出去走走的，具体的目的地不重要，主要的还是想出去练一下车；拿驾照很多久了，但是基本就没有碰过车，可想而知该忘的不该忘的，基本上都忘得差不多了。这里记录连续三个周天出去练车、顺带散心的美好春光。

一直没有确定下目的地，昨晚鬼子说徒步点醒了我；但是挺多有意思的徒步路线，都是在西北的彭州和都江堰的方向，甚是觉得南门这边就不香了。

早上又看了一下，好像只有大邑相对来说要近点了，然后就在网上又看了一篇，最后确定去大邑的云中屋，距离90公里的一样子，徒步路程1-2小时的样子，这样练车玩耍都能接受的呢。

还是双流北上高速，这次与上两次的练习，相对来说稳当多了，速度上来说也基本保持在110-130，非常不错的进步。

到大邑城区顺便见了以前的一个老友，吃过午饭寒暄了几句，继续上路到云中屋山脚也就下午1点的样子，时间来说还是很能接受的。

到达目的的先去河边悠转了一圈，跟大多数河边一样有鹅卵石还有河水😄，我想夏天这边戏水还是蛮不错的选择。

比起看水，我还是喜欢登高徒步，爬山没有登山棍是怎么行的呢，舍不得钱买那我们就自己搞一根路边别人砍好的吧。

你说这种路没有登山棍行吗，特别是下山；在你上山基本就消耗差不多的体力时，下山有一个棍子很保护膝盖哟。

不管怎样，只有自己去感受，我想这样才是最好的收获。

上周末在龙泉那边的挑花基本就快谢完了，在云中屋山上居然还有油菜花、桃花、梨子花、李子花（已谢）、木棉花等，真的是意外之喜。

<LImg :imgs="dayi4" intr="云中风景———晓风拂面" />

其实最让佩服的还是一对老年夫妇，在我们快要登顶的时候碰到了他们；这个路程对于我来说就能接受了，他们胜过我们上山时遇到的两个年轻女孩，没有开始就退缩强太多了。现在的年轻人还是要好好锻炼身体。

<LImg :imgs="dayi5" intr="云中风景———岂不知，力拔山兮" />

登山我觉得意义有时候就是在挑战自己、挑战哪些不可能，有时候并不是自己不行，是自己觉得自己不行而已。其实还是要看你自己给自己如何的定位吧，我想只有心里信仰的人才会走得更远！
