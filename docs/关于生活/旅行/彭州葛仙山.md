# 彭州葛仙山

时间一晃——一个月就这样悄无声息的接近了尾声，没错不知不觉已在家休息一个月；原本说借失业这个机会去川西短暂旅游个两三天，散散心调整一下心态的；奈何此时间段只有自己一个人是个‘闲人’，这次周末徒步距离上次徒步也恰好一个月。

上次徒步是刚刚离职的那个周末，和鬼子一起去的大邑-千佛山，到现在我也还没有补出我的游记，在家休息的我反而变得懒惰了，该死！

<LImg :imgs="gxs1" width="85" intr="彭州-葛仙山" />

这是快到葛仙山路上的风景，当画面停在快门的那一刻，一切都是最好的安排，也许旅途意义就是不经意的那一刹那；虽然今天能见度一般，但是还是能看到‘远方的诗’。

<LImg :imgs="gxs2" width="55" intr="彭州-葛仙山" />

话接上句，虽然能见度有一点点不理想，但是今天这个天气还蛮不错，在成都有好比较不错的太阳又恰碰周末的话，那么想在周边出去玩的话就是一个字——人从众。

到达葛仙山这个乡道路上的时候，不出意外的已经堵车2公里了；于是我们果断的把车停在了分叉路的路边，拐弯往前走了几步路，就来到我们这次徒步的起点。

<LImg :imgs="gxs3" width="55" intr="彭州-葛仙山" />

如果不是堵车的话，其实可以把车开到购票的门口；当然也是这种偶然的机会，才会让我们发现路途中不一样的风景。路途中还有蓄势等待的桃树，我想要是春天来的话，又是另一番不一样的天地。

<LImg :imgs="gxs4" width="55" intr="彭州-葛仙山" />

门票每人20元，门票上的解释是清洁费；门票也罢清洁也行，能给人不一样的愉悦才是最重要的收货。游玩的路线大致为两条，我们是按售票员推荐的右上左下，总体游玩下来说还是比较轻松的，很适合家庭带娃出游，具体后面后面待我慢慢道来。
