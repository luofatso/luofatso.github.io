# 大邑-小飞水

感觉每次记录的时候，都是好久什么、或者是上次什么，我在反思是不是因为我拖延的结果，我个人觉得我并不是一个拖延的人，但确实是好久没有记录抑或行动。

<LImg :imgs="xfs1" width="55" intr="这不是一篇简单的游记，这不是一篇游记" />

每一个人都有很多面，一个是自己以为的面，一个是展示给别人的面，一个是自己真正的面，一个是自己想象的面；不管那一个面都是自己的面，不管何时何地要喜欢自己，只有自己喜欢自己，才会有自己的生活。

<LImg :imgs="xfs2" width="55" intr="看着还行，千万不要去侧记旁敲" />

我感觉我有好多个自己在蹦迪，就似山气、似炊烟，在升腾、在氤氲飞絮；我想记录我的每一个他们，但又怕描绘不出那多彩的斑斓，也怕揉碎了那细碎的碎片，我总是小心翼翼的左右有为难自己。

<LImg :imgs="xfs3" width="55" intr="不要怕路上孤单，要和梦想去作伴" />

我时常在梦里像小鸟一样自由的飞翔，那种感觉像极了我儿时在麦田、在稻田、在油菜田、在山坡自由奔跑的感觉，我想回到我儿时生我长我的地方，却发现这样的机会真的好难得；你有没有像我一样，一样去追寻梦开始的地方？

<LImg :imgs="xfs4" width="55" intr="就像蒲公英一样，看似自由，却再也回不去" />

大胆点，你我都是第一次来到这个世界，都是第一次擦肩相识，有什么理由要让自己的生活变得如此的单调？走出去认识自己，你会发现，发现一些自己不曾发现的好好坏坏，起起伏伏。

<LImg :imgs="xfs5" width="55" intr="你看呀，漫山遍野的美美好好" />

我老是在不经意间想起什么，然后又在不经意间中忘却；就像静悄悄的湖面突然泛起了涟漪，不知道是鱼儿的调皮，还是波纹的匆忙，我以为什么都没有想到，我只是在不经意间中忘记了。

<LImg :imgs="xfs6" width="55" intr="我想我应该去看看，看看我的生活" />

我想写一首诗、讲一个故事、描绘一幅画；去将我看到的，我想到的，我发现的一并告诉你，我想你会喜欢的。我却制止了我那颗躁动的心，我想我应该让你去寻觅，去探索，去发现。

<LImg :imgs="xfs7" width="55" intr="我以为我知道，一半是生，一半是活" />

好了，今天的故事就到这里了，我想你会明白——我想要告诉你的。生活再苦没有黄莲苦，黄莲在苦没有生活苦，你说我在说什么？我说我没有尝试过，我说我们可以一起去走上一遭吗？

我想这样也是最好的如果，至少不用我们去苦思冥想，却又欲言又止。谁让我们相视而笑，又相忘而忘！
