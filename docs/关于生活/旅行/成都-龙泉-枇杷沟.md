# 成都-龙泉-枇杷沟

特此记录，练车三连：

- [新津-斑竹林](./新津-斑竹林.md)
- [成都-龙泉-枇杷沟](./成都-龙泉-枇杷沟.md)
- [大邑-云中屋](./大邑-云中屋.md)

这个季节还是比较想出去走走的，具体的目的地不重要，主要的还是想出去练一下车；拿驾照很多久了，但是基本就没有碰过车，可想而知该忘的不该忘的，基本上都忘得差不多了。这里记录连续三个周天出去练车、顺带散心的美好春光。

原计划是准备去崇州-静翠园挖折耳根的，不得不说折耳根还是四川人的最爱；但天公不作美，一下高速雨就雨下大了，觉得没有必要再冒雨去找快乐😂，然后加完油就准备回去了，一个不是完美的周末。

就在回去的掉头的路口，车速没有控制好，被骂了一番😄。但是车的熟练度是上来了。

胆子还是可以，上周跑了一天，就熟悉了那么一下下，本周将就敢跑高速了，佩服我自己。其实并没有那么顺利，很久没有开车基本其实都忘记了，老是跑去看雨刮一只修方向盘，原本也没啥的，也能勉强在高速跑；但是下了点下雨，一开雨刮就像人失去了主心骨马上就不知所向；看来这样子是不得行的呢，只能靠应急让鬼子来了。然后自己缓解了一下情绪交流了一下心得，所以回来的时候自己上手还是蛮不错的。

回程的高速上，还是心有不甘，我们最后决定去龙泉阳光城，眼仔在那边说的没有下雨呢，刚好有段事件没见了。

<LImg :imgs='img1' intr="龙泉枇杷沟-观赏桃花" />

午饭后我们决定去了枇杷沟，抓了抓春天的尾巴，观赏了一下有是快谢的桃花。周末出游的人还是蛮多的呢，第一次开了这种山路，路还是比较宽阔，上山还是比较从容。

下山出了点小小的意外，出停车的小平台的时候，没有掌握好距离眼看出不去，想的是准备踩刹车停下来倒一下就好了，却错踩了油门；然后就硬出去了，还好是一个小木干，把后视镜的玻璃蹭掉了，也是把自己吓懵逼了。

<LImg :imgs='img2' intr="龙泉枇杷沟-桃花" />

安上后视镜的镜片后的回程，心有余悸迟迟走不出那一幕，宝宝和鬼子也是吓得不浅的，一路上都是提心吊胆，自己把自己是累得不行；根据一次的过失想想，我觉得就像人生一样，那有没有过失呢，主要的是放下过失，这样自己就会轻松很多。
