# 成都-绿道

绿道，是多少痴男怨女的未竟承诺，是几世魂牵梦萦的未达愿景，更是夜深人静时，反复描摹却触不可及的一场旧梦。

## 第一次

<!-- 终于等到你，还好没有放弃；是回忆、是梦境、是以往的回忆。一直以来我都在想，想去追寻，想去超越，这一次... -->

终于等到这一刻——还好，从未放弃。是记忆深处的潮涌，是梦境边缘的微光，是所有未竟往事的回响。这些年，心底总有个声音在催促：去追寻，去跨越那道地平线。而这一次，我不再犹豫。

## 老友

这一次我们不骑绿道，我们去见老友。

<!-- 不知是记忆的错觉，还是感知的麻木，有种时间总是在追赶着、鞭笞着我前行，我疯狂的蹦跑，却处处被我自己的限制所束缚。 -->

不知是记忆篡改了时间，还是感官早已蒙尘，我总被无形的鞭影驱赶，在自我设限的迷宫里——一场精疲力竭的逃亡。

<LImg :imgs="ld11" width="55" intr="是昨天，是今天，是明天" />

<!-- 我们一直在忙碌，一直在奔波，还在为自己的忙碌自我感到，歌颂；停下来的时候才知道自己才是无头苍蝇，生命总是在当下，在此刻。 -->

我们总在奔跑中将自己铸成一座丰碑，用忙碌的金箔贴满表面。直到某个静止的瞬间才惊觉——那被歌颂的轨迹，不过是玻璃上无头苍蝇的嗡鸣。而生命，永远只在呼吸抵达成此刻时，才真正开始颤动。
