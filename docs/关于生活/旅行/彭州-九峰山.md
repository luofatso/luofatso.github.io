# 彭州-九峰山

‘生活不止眼前的苟且，还有诗和远方’，曾经我也想仗剑走天涯，后来因为生活的柴米油盐就没有去成...但是不管如何都不能阻扰我前进的脚步

<LImg :imgs="jfs1" width="55" intr="在别人的视频里，在我的手机里" />

九峰山——就隐隐约约的好像是在什么时候，自己抛出的一个豪言壮语、一个不为人知的秘密，在梦里、在峰回路转的记忆里。

<LImg :imgs="jfs2" width="75" intr="在我的眼前，在我的记忆里" />

很久之前就埋藏心里，今天我终于来了。要说多激动其实也不然，就好像一个人中的重大光辉时刻一样，正在聚光灯下有时候我们是并不知道的。

<LImg :imgs="jfs3" width="75" intr="是普普通通的，也是不同凡响的" />

你是喜欢旅游，还是喜欢旅行？不有急着回答我，在心里回答自己就好。没有什么事标准的答案，也没有什么是回答不了的，实在不行我们还可以请求神灵。

<LImg :imgs="jfs4" width="75" intr="总是有很多想分享的，说明什么呢" />

我是喜欢徒步的，因为不仅仅是给予了心里的享受，还赋予了我身体的洗涤；也许是我那疲惫不堪的灵魂，抑或是我的那满是昏尘的梦眼。

<LImg :imgs="jfs5" width="75" intr="是说明我在成长，还是没有长大" />

一路上总是走走停停，惊呼叹奇。说说笑笑，

<LImg :imgs="jfs6" width="75" intr="我想是左，也就是右，都还是存在的" />

总还是有收获的，至于分不分享，我觉得还是要看这个人是否是被这个世界的一点杂念污秽没有。有点人总是喜欢装深沉，至于有没有错其实也不然，还不是心念不一样而已。

<LImg :imgs="jfs7" width="75" intr="人生而何为人？" />

经过一个小时的石梯路途，我们到达了祖师殿。我们并未休息而是直接继续前面的路程，也许是前面未知的奇妙路途，勾起澎湃的心血。

<LImg :imgs="jfs8" width="75" intr="平平常常才是真，也才是生活的大多数" />

前行不就就能到达第一处塌方的地方，风景确实相比石梯处的大有不一。你是不是喜欢这样的不一样的呢？对呀，人生又何尝不是不一样呢，但是也许你也许并不喜欢，因为不一样的也许是伤痛，是刻骨铭心的。

<LImg :imgs="jfs9" width="75" intr="就算那些不一样的，成了大多数，那就也成了少数" />

所以既来之，则安之。大多数的是我们自己不能左右的，我们能做的就是做好当前的。不管我们喜不喜欢，反正那些记忆犹新都是非同凡响的。

<LImg :imgs="jfs10" width="75" intr="多多少少，也就是平平常常" />

你们在生活中的有时候，是否总有想要去分享点什么的没有呢？这样对吗，因为自己在生活中是一个唠叨的人，所以有时候就总是想去分享、去讨论一些，关于自己所认知那些凤毛麟角的东西。

<LImg :imgs="jfs11" width="75" intr="在这样的塌方乱石下逗留，确实是安全的吗？" />

其实我也在想，如果自己不表达出来，你自己是不是也并不知道自己的对错；但是说出来会不会暴露自己的无知，但是不暴露自己的无知，那又从哪里来的进步呢？

<LImg :imgs="jfs12" width="75" intr="路途中最少的是哪一段的人呢？" />

可能我想还是得看自己讨论的出发点吧，你要是在学习的角度那就是在进步；你要是在指指点点、或在个人表演，那就是挖坑，你要知道的就是没有人喜欢那些自以为是的人。

<LImg :imgs="jfs13" width="75" intr="路途中间才是人最少的一段，也许它就是寂寞的" />

这次出来徒步又是我们早上临时决定的，原本是想去一个比较一般的线路的，但是好久没有活动开的我们最终还是选择了有分量的——九峰山。

<LImg :imgs="jfs14" width="75" intr="你看，人又多起来了..." />

确实没有让我们失望，九峰山——让我们历历在目。早上临时出发没有准备太多的食物和水，我们到达徒步地点开始徒步已经11点了，原本买的士力架两个在车上也被吃了，下高速的一碗二两面条也顶不住了。

<LImg :imgs="jfs15" width="75" intr="再见南天门！上次是在哪里来着..." />

路上总共带了三瓶水，水在快到观音岩的时候我两也喝光了最后的一点，唯一买的速食米饭里面只有一袋水，你说找谁去说理去呀！驴友——对，没有难道在路上的人，感谢一对情侣投喂的两个饼干。越在到达顶峰的时候，云雾就越大，温度也就是越低，原本就高负荷低补给的我们，已经逐渐有失温的表现，在这么高的地方失温是个很可怕的事情。

我们到达南天门的时候，朋友已经筋疲力竭，停下休息会儿和下山的驴友了解就快了，又才靠毅力和眼见的希望继续往上的。确实从刚开始徒步到祖师庙那段的石梯路虽远，但难道相比后面是真算不了啥；但是那段流汗是真不少，算一个不错的热身，难道系数我打3分。

随后就是祖师庙到罗汉洞这段，这段就是塌方和正常的山间小路，难道系数肯定就比石梯大了一丢丢，所以我给这段路难道系数打4分，最多也多不上去，不然后面的分就要超出范围了，会被视为作弊。

从第罗汉洞到观音岩这段，我觉得才是真正的景区收费路途，前面的就只能算其他景区的免费路段；并不是说它是收费景区，而是想拿它和收费的景区来说衬托它该有的价值；但是拿钱来对比它的价值，会不会又觉得未免庸俗了些，奈何又想我自己不就是一个凡夫俗子嘛。对于这段的难道系数就直接上到6分，没有遵循循序渐进的规则，而是前面的路途就做好足够的铺垫。

<LImg :imgs="jfs16" width="75" intr="无限风景不一定在顶峰，也是顶峰" />

从观音岩到南天门这段路途的难度，我觉得才是‘赵九铁’名至所归的由来；有点类似直线攀登的感觉，海拔蹭蹭的直线攀升，这也许是因为自己物资没有准备充分，当然也有可能是因为我们前面那些路走得太过轻浮——也有可能是自己过于浮夸...也许是没有合理规划使用体力，反正不管如何，却使得我们在这段路上显得尤为的艰难。

也感谢快要登顶一个大哥分享的花生糖和酸奶，简直就是人间甘露甜到久久不能忘怀。听他们说山上有卖泡面的还能烤火，对于我们当时来说是一个激奋人心的好消息；登顶后已起的云雾也没有多少心情顾及，直冲泡面和温暖，由于山顶没有网络所有购物还得靠现金，这里再让我感谢小姐姐借我50大洋。
