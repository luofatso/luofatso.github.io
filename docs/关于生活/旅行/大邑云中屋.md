# 大邑云中屋

练车三连记录

## 新津斑竹林

这个季节还是比较想出去走走的，具体的目的地反正也没有；主要的还是想出去练一下车，拿驾照很多久了，但是基本就没有碰过车，基本也都忘得差不多了。这是我连续第三个周末的周天出去练习了，熟悉得也差不多了。

第一周我们去了新津的斑竹林，因为是很久的第一次练习，所以宝宝没有一起去；有点可惜，想一起看不一样的的风景。

很久没有开，一个人练习肯定是不敢的，叫了鬼子能给我提示。这个家伙第一次就怂恿我上高速，还是很久碰了，先熟悉熟悉，所以走的国道。

因为前面宝宝要考试，所以一直没有提前点出去，春天的尾巴差点都没有给摸着，来几个路中快开谢完的油菜花。拍照技术有限，一直觉得无所谓，但是我绝还是要突破自己的心里防线，不要觉得自己拍不好就不去着摸，就心甘情愿当个不是专业，我觉得我心态还是需要多多调整一下。

新津斑竹林还是有点园林的气息，但是不多，哈哈。我更觉得想故乡家园的感觉，感觉就应该朴素，简单。其它的就跟公园一个感觉了，没有什么特别的别具一格，中规中矩，比较适合周末带小孩纸和老人散散心。

## 崇州静翠园 - 龙泉枇杷沟

原计划是准备去崇州静翠园挖折耳根的，不得不说折耳根还是四川人的最爱；但天公不作美，一下高速雨就雨下大了，觉得没有必要再去冒雨快乐，然后加完油就准备回去了，一个不是完美的周末。

胆子还是可以，上周跑了一天，就熟悉了那么一下下，本周将就敢跑高速了，佩服我自己。其实并没有那么顺利，很久没有开车基本其实都忘记了，老是跑去看雨刮一只修方向盘，原本也没啥的，也能勉强在高速跑；但是下了点下雨，一开雨刮就像人失去了主心骨马上就不知所向；看来这样子是不得行的呢，只能靠应急让鬼子来了。然后自己缓解了一下情绪交流了一下心得，所以回来的时候自己上手还是蛮不错的。

回程的高速上，还是心有不甘，我们最后决定去龙泉阳光城，眼仔在那边说的没有下雨呢，刚好有段事件没见了。

午饭后我们决定去了枇杷沟，抓了抓春天的尾巴，观赏了一下快谢的桃花。周末出游的人还是蛮多的呢，第一次开了这种山路，路还是比较宽阔，上山还是比较从容。

下山出了点小小的意外，出停车的小平台的时候，没有掌握好距离眼看出不去，想的是准备踩刹车停下来倒一下就好了，却错踩了油门；然后就硬出去了，还好是一个小木干，把后视镜的玻璃蹭掉了，也是把自己吓懵逼了。

安上后视镜的镜片后的回程，心有余悸迟迟走不出那一幕，宝宝和鬼子也是吓得不浅的，一路上都是提心吊胆，自己把自己是累得不行；根据一次的过失想想，我觉得就像人生一样，那有没有过失呢，主要的是放下过失，这样自己就会轻松很多。

## 大邑云中屋

一直没有确定下目的地，昨晚鬼子说徒步点醒额我；但是好多好多有意思的徒步，都是在西北方向的彭州和都江堰的方向，甚是觉得南门这边就不香了。

早上又看了一下，好像只有大邑相对来说要近点了，然后就在网上又看了一篇，最后确定去大邑的云中屋，距离90公里的一样子，徒步的路程1-2晓得样子，这样练车玩耍都能接受的呢。

还是双流北上高速，这次有上两次的练习，相对来说稳当多了，速度上来说也基本保持在110-130，非常不错的进步。

到大邑城区顺便见了以前的一个老友，吃过午饭寒暄了几句，继续上路到云中屋山脚也就下午1点的样子，时间来说还是很能接受的；
