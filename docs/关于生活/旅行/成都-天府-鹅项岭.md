# 天府-鹅项岭

我开始以为鹅项岭属于龙泉，因为它在龙泉山脉上，就这么简单的联想——是不是很肤浅；最后查寻了一下，它以前是属于双流，现在是属于天府新区。其实它隶属那里真的并不重要，主要是这寻根刨底的该死精神在作祟。

<LImg :imgs="exl1" width="85" intr="鹅项岭-徒步起点" />

鹅项岭徒步整体比较轻松，比较适合带娃和周末不知道走哪里去散散心的小伙伴。关于导航到这个鹅项岭公交站就行，此处就有停车点但是比较少，至于往前和左上其实都可以的。只是前行停车不方便，左上的或可以直接停车在石头房子的下面路旁边。

<LImg :imgs="exl2" width="85" intr="鹅项岭-滚牛坡" />

由于我们来得相对来说比较晚，前面两个停车点都没车位了，所以我们继续往前找到了，有一个比较大的免费停车点。停车时才想起这地方我们几年曾经来过，甚是熟悉——仿佛时间就停留在昨天。

我们往回的方向步行一两百米，从滚牛坡的景点进入开始散心，因为难度确实也不大，和两好友交流心声赏悦一路风景，生活其实就是在当下。

<LImg :imgs="exl3" width="85" intr="鹅项岭" />

其实都这个季节了，居然还这么枝繁叶茂，百思不得其解，有时候在想是不是，如果说把川西看着是成都的后花园，那龙泉山又算是成都的什么

<LImg :imgs="exl4" width="85" intr="鹅项岭" />

天气一般，不然又看完成都了
