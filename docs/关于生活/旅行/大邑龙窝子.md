# 大邑龙窝子

大邑——龙窝子，今年很早之前就打算去游玩一番的，但也因各种因素迟迟未果；但是这份种子早已悄悄埋藏在我心底深处，经过中间这段时间的酝酿，它的根也已蔓延到我心中四处八方各个角落，我知道它只是在等待一个更为恰好的时机。

<LImg :imgs="lwz1" intr="一颗种子的发芽" />

网上攻略说不能直接导航龙窝子，好像说不然会走错路（我想是缺少了路途的美）；我们按推荐的地点导航到混元宫，从成都开车过来差不多一个半小时；其实可以导航‘远山小筑’名宿，甚至你可以开到步行点，但是路有点陡峭（本人新手菜鸟😂）。

<LImg :imgs="lwz2" intr="是为你，有心的你，开遍——满上遍野" />

从混元宫起点出发，好像有两条路是可以上山的，但当时我们并不是很清楚，只是随着大流走了左边的道路；网上说的那个水厂应该是在右边的那条道路上，个人假想意识里感觉没有走的那条路更有‘风景’，也许没有看到的永远是最好的吧...

<LImg :imgs="lwz3" width="85" intr="给你除草，给你施肥，给你肆意生长" />

道路两旁有或零散或聚集的人家，有戴着草帽正在除草的嬢嬢，有近在眼前的炊烟和青山，更有那肆的野花和可爱的庄家，这和谐而自然的幕幕，心中也便似这一缕缕清风一样轻柔。

<LImg :imgs="lwz4" intr="在心底、在心里——最初梦想开始的地方" />

同当前村道公路在山中、在林宇间，或崎岖陡峭、或缓慢平和，一起差不多穿梭攀爬了一公里多吧；我们终于来到了，我觉得堪称是此次登山的起点，我想也许是因为跟在心底、在心里——最初梦想开始的地方很相似吧！

<LImg :imgs="lwz5" width="100" intr="你就是我的‘芳心’" />

为了能让小宝贝陪同我一起出来走走，我也是使出了千方百计，真的是煞费了苦心；从几周前就开始慢慢沟通，为此我还特意为她买了登山棍；功夫不负有心人✊，终于是在本周早点的时候得到了她的‘芳心’💞...

<LImg :imgs="lwz6" width="100" intr="看，青山和清风一起相拥" />

虽然我也可以一个人出去，小宝贝也是允许的；但主要我还是觉得天天坐办公室，时间久了身体多少还是会有一点亚健康，她平时加之又不太喜欢运动；其实我想说的是这些都是借口，我更想带上小宝贝一起去感受不一样的美景。

<LImg :imgs="lwz7" width="100" intr="看，青山和清风一起相拥" />

小石梯步上来没多远，就全是这种硬化的小路；小路的边侧还有钢索护栏，给人安全感满满，也甚至感受不到一点违和感，行走在这山间，人与自然相得益彰。 没有被商业化
