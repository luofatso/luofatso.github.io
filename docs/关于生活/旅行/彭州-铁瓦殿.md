# 彭州-铁瓦殿

> ⛰️铁瓦殿不是一座庙，而是一座山。山顶海拔3450米，山脚海拔1100，位于四川彭州市小鱼洞。顶上有200多平方米的杜鹃灌木平台，地势较为开阔，是很好的360度的观景平台。能见度好时，能将四周所有高山，远的如贡嘎雪山、四姑娘山、巴郎、鹧鸪、雪宝顶，近的如光光山、太子城、九峰山，尽收眼底。运气好的话有可能还能遇到山中特有的日出、云海、佛光等自然奇观。
>
> 💪 一路途径泥泞小路、碎石路、丛林、山脊、沟道、悬崖、绝壁等，考验着我们的体力和毅力。手脚并用的攀爬，让人仿佛进入了另一个世界。
>
> 🌤️ 冲天坡是登顶的必经之路，陡峭的石坡让人望而生畏。但正是这些挑战，才让徒步之旅更加刺激、有趣和着迷。
>
> 💖 铁瓦殿徒步之旅，虽然*痛*但并`快乐`着，每一次的挑战都是对自己肯定、挑战和突破。
>
> 🚙 自驾：导航`中坝森林保护站`，最好早上7点前，否则你就只能走路或者做本地的车。
>
> 🎫门票 | 0元

<LImg :imgs="twd1" width="45" intr="开始-结束-开始" />

在成都户外人有句话：入门赵公山，进阶九峰山，毕业在铁瓦殿，爬完“赵九铁”，川西随便野。

我自己也懒得开这个玩意，图都是在圈里盗取的，有时走不动的时候可以拿出来激励一下自己，感受一下痛并快乐。

<LImg :imgs="twd2" width="45" intr="在老家的时候是一动不动" />

我们是从中坝村开始徒步的，那里是有本地村民车可以直接送到这个停黑车的村名家这里；但因上次来过中坝森林感知并不值得，所以还是毅然不决的走了上来的，近半个小时的铺装路是真无趣（主打一个我不服）。

从农家这里开始徒步，就算我们今天开始真正的征程了——加油，各位好自为之...

<LImg :imgs="twd3" width="45" intr="轻松，简简单单" />

仅仅十几分钟还是半小时来着，我们就到达了大悲寺，我为我们可怕的强大感到无比的自豪。哈哈，是吗？继续

<LImg :imgs="twd4" width="45" intr="不，我能把持" />

啃根黄瓜，吃点路边的`刺泡`，这徒步简直不要太安逸了吧。童年金色的回忆，又在我脑海里左冲右撞啦，根本就把持不住。

<LImg :imgs="twd5" width="45" intr="年轻人，话不要说得太早" />

前面那节的烂泥路我们忙着赶路，怕摔着（忘记了）——没有拍照，但是不得不说对得起‘泥瓦殿’这一称号；你们要是小时候没有把泥巴玩够，抑或想拾起童年那份独有的乐趣，那你亲自来上一遭我敢保证绝对不会枉来此行。

一路有好几个在烂泥里摔得不成样子的，看着他们杵着登山杖蹒跚彳亍、憨态可掬的样子，真的一个微笑能诠释所有。在哪里摔倒就在哪里爬起来，一次徒步就是一次人生，哪有什么自由自在，多的还是身不由自，看透依然热爱。

<LImg :imgs="twd6" width="45" intr="等风来，不如追风去..." />

累了要懂得休息，看看风景，调节一下那酸爽的双脚和心肝；有人说看了风景还是得回去当‘牛马’，但是看了风景它能调整自我的焦虑、戾气...让我更好的当‘牛马’，让我当更久远的‘牛马’。

面有心生——看风景，就是风景，不会是人生，看看看风景的人，我们都是风景。等风来，不如追风去...

<LImg :imgs="twd7" width="45" intr="年轻人，话不要说得太早" />

我们是端午节徒步的铁瓦殿，前面的路程我记得他们当时还说铁瓦殿也不过如此，根据上次去九峰山的经验直觉告诉我事情并不会这么简单，我还劝解他们不要嘴硬。当然虽然嘴硬，但也还是有那个实力🤣，除眼仔平时运动比较少中途放弃，我们的登顶的决心却一直没有动摇。

因前面烂泥路前面那段时间耽误了，所以我们后面碎石路、冲天破都是那种不怎么带休息的，不过脚板还是有点酸爽呢。再要登顶的那大片怒放的高山杜鹃，在云雾中若隐若现甚是一绝，美丽的花在春天是不稀缺的，但要在这高山之中如此大片怒放，我想是他们骨子里独有的姿态。

<LImg :imgs="twd8" width="75" intr="会当凌绝顶，啥也看不见" />

跟上次去九峰山一模一样，又是一个云里雾里冲撞的少年，那又何妨呢——只要不服输的信念一直在我心，头破血流总能见昭昭，不要问我昭昭是谁，问我我就是张无忌👍。

铁瓦殿上面那个牌牌也不知道是谁搞走了，上去就是一片空旷的平台，不是在云里雾里，我想我应该是在云彩里。

一起比个茄子，然后收拾收拾心情打道回府，原以为本次就这样结束了...

<LImg :imgs="twd9" width="45" intr="是中国人的，独有的浪漫" />

下山的路上其实时间并无结余，因为赶夜路下山是不明智的举措，但奈何天空有情让我在回程如此留念、痴迷。

<LImg :imgs="twd10" width="75" intr="山，是一座山" />

看过很多水，也见过很多山，山还是最令我心之所向，山——不仅是一座山，更是一座山。

<LImg :imgs="twd11" width="45" intr="路，是回家的路" />

忙着赶路的人儿啊，请停下你那匆忙的双眼，我们一起去追寻、去感知、去遗忘...

<LImg :imgs="twd12" width="45" intr="画，是夜里的梦" />

古人的山水画它真的不曾骗我，是写实，而不是单纯的形式美。山青如黛，此刻只想静坐如此，连蚊虫都醉如钉，我被它们的沉醉而沉醉。

<LImg :imgs="twd13" width="45" intr="夜，是梦里的山" />

有的夜，是你不想赶的夜；有的路，却是你必须要赶的路。

不要被前面的路而迷失了后面的路，不要被后面的路而错过了前面的路，我们一起慢慢走我们自己的路...

<LImg :imgs="twd14" width="45" intr="来过的痕迹，会淡忘，不会遗忘" />

铁瓦殿的蚊虫是真的厉害，我原本早就做好了准备，穿了长袖的衣服裤儿，但还是防不胜防。这腿上的印记可是一个月后的疤痕，可想而知是真的毒。

::: tip 提示

- 日出、云海、佛光等自然奇观还是要开天气情况的，所以有想看的得提前看好天气情况。

- 一路没有补给点，食物和水一定要带充足，高山失温是件很可怕的事情，不可儿戏。
  :::

::: warning 注意

- 高山地带天气多变，要去的小伙伴一定要注意提前看好天气情况，做好防雨、防雾、防风、防晒、防滑、防寒的准备和工具。

- 铁瓦殿看着路程不是很远，但是海拔爬升还是在的，时间一定要留充足，下山带好灯具，不建议没有经验的小伙伴夜爬。
  :::
