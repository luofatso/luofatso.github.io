# 康定-木格措

不知道从多久开始，内心居然开始有‘逃离’城市的想法——愈演愈强烈！就像是一颗在黑暗里蓄势待发，而迟迟没有得到雨露的召唤，被压抑而又疯狂生长的种子。

我想这不是一个好的生活状态，也许是身体累了，我想更多的是心灵疲惫了。那就趁着端午好好给心灵放一个假吧，我们去有风的地方好吗？

<LImg :imgs="mgc1" width='85' intr="318第站——木格措" />

我们原计划就是准备去川西的，中间因为天气预报好像说要下雨，犹豫半响过后，我们毅然坚持抉择永不退缩。为了不和大家一起拥堵在路上，我们早上6点50就出发，同时我们还选择了反向游玩路线，所以一路上一点都没有出现堵车的情况，暗喜这样不错的选择；到达木格措景点也就才10点半，这个点我个人觉得除了看不了日出外，其它的都还是蛮不错的。

<LImg :imgs="mgc2" width='85' intr="是来自心底的喜悦" />

我们刚刚停好车，太阳就穿过云层特意跑出来欢迎我们的到来，我想它如此热情的接待应该是本地人狂热内心的外射感化吧！

<LImg :imgs="mgc3" intr="木格措汉名野人海，又名大海子" />

曾经你有没有和我一样心中疑惑，为什么川西西藏等地把湖泊称为什么什么海子呢？如果说是本地人没有见过海，我想那是多愚昧、多无知的想法呀！当然原因除了地理环境、文化特色、语言习惯以外，我想更多的是本地人对它们崇敬、神圣和敬畏的独特情感吧！

<!-- 是我们心灵和精神寄托的地方 -->

<LImg :imgs="mgc4" intr="来自‘天山’——圣洁的冰雪之水" />

沿着这圣洁的冰雪之水一路向上，让我们一起去探索下一个神秘之境——我称之为‘天空村寨’，一个可以让心灵、精神放飞的地方。

<LImg :imgs="mgc5" intr="一个可以让心灵、精神放飞的地方" />

仅此一段几步之遥，一个质朴、原始、安静的村落现入眼帘，它简单却又如此的温暖，像极了一个慈祥而富有智慧的老者——在守望、在等待、在述说。

<LImg :imgs="mgc6" intr="守望着过去的辉煌和曾经的故事" />

他在守望古老的记忆、守望着过去的辉煌和曾经的故事，每一个石头、每一栋老房子都是岁月的见证。在守望中，他似乎在向人们传达着一种坚守和承诺，让人们记住过去，记住历史，记住传承。

<LImg :imgs="mgc7" intr="等待着黎明的曙光和新生的花朵" />

他在等待未来的希望和时光的循环，他倚靠在大自然的怀抱中。他等待着黎明的曙光和新生的花朵，期盼着繁荣的未来，绽放出绚丽的颜色。

<LImg :imgs="mgc8" intr="讲述着英勇的英雄和深邃的爱情" />

在述说着古老的传说和智慧的精髓，村庄的声音如古老的童谣轻轻传颂。他讲述着英勇的英雄和深邃的爱情，将智慧的火焰代代相传，不曾停息。

<LImg :imgs="mgc9" intr="我这该死的脚步也贪婪得想和时间一起就停留在此刻" />

继续一路随风走走停停，伴着清脆的马铃（游客骑的马，160一人，平穷限制了我的想象）由远到近，再由近到远最后消失在耳朵的云雾之中；这如诗如画的地方仿佛时间也沉醉其中，我这该死的脚步也贪婪得想和时间一起就停留在此刻。

<LImg :imgs="mgc10" intr="晴朗明媚、灿烂温和" />

川西变化莫测的天气，犹如恋爱中的女子，上一秒可能还是晴朗明媚、灿烂温和，下一秒也许就是乌云密布、风雨交加，让你无法捉摸她的魅力和神秘，这也许就跟爱情一样充满无限惊喜与奇妙。

<LImg :imgs="mgc12" intr="木格措——七色海" />

由于中途突如其来的风雨，使得我们也不得不加快了游玩的脚步，再加上我们只带了一把雨伞，所以中间就省去了‘杜鹃峡、药池沸泉’景点，甚是可惜啊，回想也许遗憾才是完美的主旋律。

<LImg :imgs="mgc11" intr="是来自心底的虔诚" />

七色海，我想这个景点晴天应该才能完全诠释它美吧。下雨全是雨水雾气笼罩，如若有雨具行走其中，我想应该又是另外一番独特唯美的山水墨画。

::: info 讨论
就景区骑马这个项目，我个人觉得特殊情况除外，最好还是坚持自己步行来得好；因为大多数人出来玩不就是图个释放嘛，释放内心的焦虑、疲惫等，然而步行和景色同时都可以释放内心的一切杂念，身体的疲惫也许才会治愈内心的伤痛。如若真的想感受骑马，为什么不去策马奔腾，反正在这崎岖山里折腾自己，当然每个人的想法不一，感受一次又何妨呢！

还有就是景区摆渡车，这个话题我们就留在下期在讨论吧。
:::

::: tip 提示
等返程回景点入口的摆渡车的时候，我们和同行的其它小伙伴们，讨论起了各自买的牛肉干，他们买成160而我们才90，味道及干湿度基本无异；具体了解才知道他们是在草原口买的，而我们是在往景点深处里的一个阿姨家买的，所以买东西还是多了解，毕竟景区宰人还是挺多的。
:::

::: warning 注意
吃宿的话我们就建议去康定市区，牦牛肉菌汤还是管够，价格也能接受；住宿需要多注意一点，我们当时住宿是一个小区套房改造的，晚上嘈杂导致并没有休息太好。

川西天气变化莫测，跟川剧变脸一样之快，之诡！所以**墨镜、防晒、雨具、保暖**是必备哟！
:::
