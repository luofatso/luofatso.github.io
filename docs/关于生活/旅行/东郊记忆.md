# 东郊记忆

东郊记忆，很早就听说过这个地方，一直都不知道它属于那种类型的游玩景点，感觉它对于我来说一直是一个神秘的存在。

<LImg :imgs="dj1" width="75" intr="记忆的深处" />

当然一直也没有去探索它是如何的一个存在，我想一直保持神秘感也许就是最好的存在；我也相信总有一天我会亲自去揭晓它神秘的面纱，这不今天我们满怀期待的来了。

<LImg :imgs="dj2" intr="以为只有如此之时" />

刚一进入感觉有点冷清，我想是我们到的时机有关系吧；因为昨天有点劳累，所以今天早上就多贪休了一会儿，我们到达都下午一点钟了，这个时间点刚好是最热的时候，我想我们是算错了时机——也许是那些沸腾着并带着晚霞的傍晚！

<LImg :imgs="dj4" intr="记忆的深处" />

开始我还以为是废弃的仓库什么之类的，但是后面当我看到路边的机床和‘东郊记忆’这个名字后，我想这应该是以前得某一个老工厂，应该对成都、对祖国有过相应卓越的历史功绩，所以被改造为特色景点吧。

<LImg :imgs="dj5" intr="美好的时光，昨天，今天，明天" />

美好的时光，昨天，今天，明天

<LImg :imgs="dj6" intr="一切，你都是如此的热爱" />

是画，里面有随处可见的生动而有趣的画作；回想起曾经的我也又过几天艺术学习，只是没有坚持下来，我想也许是我与它无缘吧😭！是怎样热爱生活的人才有如此化跳动的画作呢——我是热爱生活的呀🤩...

<LImg :imgs="dj7" intr="不予言说的千言万语" />

饶了一圈，我就说人都跑哪里去了呢？原来是都跑来看各种展览来了，恕我无知！当然排队等待看展的人已排起了长队，但是我个人觉得艺术是需要时间慢慢去欣赏的，就像它需要时间去沉淀一样；如若这样被推挤而憋飘一眼，无疑就是‘囫囵吞枣’，对于我个人来说是难以接受的。

当然这里这两个免费的，至于其它的——我知道，我来与不来，你就在那里，如若有缘，我们总会相遇！

<LImg :imgs="dj8" intr="记忆的深处" />

每次看见这种绿皮火车，总能让我有千般蠢蠢欲动的思绪——曾经那个青葱岁月的自己，总是有不可一世的精神，羡慕那时的年轻...因为它承载着我的全部青春！

<LImg :imgs="dj9" intr="记忆的深处" />

最后我们一如既往，留下来过的痕迹吧；是的，无痕——却承载着所有！
