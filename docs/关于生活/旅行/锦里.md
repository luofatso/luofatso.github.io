# 锦里

五一第一天我们决定去锦里玩玩，去做一次游客，去感受一下成都节日的‘烟火气’。

<LImg :imgs="start" intr="好天气，好心情" />

我已经记不起第一次去锦里是多久了，大概是我刚上班的那一年吧，第一印象跟洛带古镇有点相像——人多、小吃多、有点繁华的拥挤！



我们总是匆匆忙忙、忙忙碌碌——其实我们不怕身体何种的劳累，因为只要休息一晚，第二天都是新的；但现在大多的人的心累，是真的很不好找到出路，就像迷了路的小鹿，跌跌撞撞总找不到归路！

你有没有像我一样，有时候在寻找一件东西的时候打死都找不到，等你过往之后它有悄悄的出现了，我想也许使我们当时太着急了吧！就跟迷了路的小鹿一样，我想大多时候都是太过慌张；当前的路行不通的时候，也许我们该停下来休息一下，做做其他的事情，或许我们会茅塞顿开，会雨过天晴！

惊扰你的我想我不是归客，我们只是一个个过客而已！
