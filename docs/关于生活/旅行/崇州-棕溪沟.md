# 崇州-棕溪沟

夏日炎热，我们要去就要去有风的地方，等风来，不如追风去...

<LImg :imgs="zxg1" width="55" intr="等风来，不如追风去" />

周末约上三五好友，一起去山里撒泼卖疯，可以释放一周堆积的‘毒素’，让自己做更好城市里的牛马。

<LImg :imgs="zxg2" width="55" intr="一点浩然气，千里快哉风。" />

为什么一开始就这么累，有没有一种可能——因为一开始你就走的上坡路，不要放弃，坚持下去后面的路会更加的陡峭。

<LImg :imgs="zxg3" width="65" intr="要自由，做自己" />

你管后面的路干嘛，好也罢，歹也行；千千万万个都有可能，路上的风景感受才是自己的收获，没有什么属于自己，只有过程才是丰富生命的篇章。

<LImg :imgs="zxg4" width="65" intr="去看看吧，听听也行" />

说好的不要管路的呢，怎么这次全是行路的照片呀，让我一点开拓的思维都没有打开，可能是我没有上心，可能是我只专注行路了。

<LImg :imgs="zxg6" width="65" intr="这路途，是归程" />

有一说一，这次的路程丰富度还是比较高的，溪水、丛林、竹林、野花、峭壁...我一一念念不忘。

<LImg :imgs="zxg7" width="65" intr="是生命，多灿烂" />

那火红的树莓是我按耐不住的童年梦境，是春天、也是夏天，是昨天，更是今天，是生命，多灿烂呀！

<LImg :imgs="zxg8" width="65" intr="是路途，是归程" />

相对来说明明是比较轻松的路途，却让我如此疲惫，是身体，是灵魂，是生命。

<LImg :imgs="zxg9" width="65" intr="是路途，是归程" />

是以往的回忆，是现在的回忆，是未来的回忆，是记录的点点滴滴...
