# 龙泉紫霞山

大好时光，难得的周末艳阳高照，你真的不出去走走嘛！

## 兴隆湖

不出意外的，先跑个题去去兴隆湖吧。

<LImg :imgs="xinglong1" intr="你还别说，这么一看有真有点海滨城市的感觉" />

原计划天气好准备去三圣乡花市的，但是媳妇嫌弃太远，怕我们的‘宝马’跑去就回不来了；做我就临时调整去围兴隆湖一圈的，当然不出意外的话，我们又结束了开始的开始。

<LImg :imgs="baoma" intr="我家的‘宝马’" />

记录一下我的‘宝马’，快两年了好像就没认真给它拍一张，真的一点‘仪式感‘都没有。罪过罪过...

以前一听见‘仪式感’这三个字就特烦，也许是大多数男生的公敌吧！现在慢慢好像有点明白，‘仪式感’其实并不只是我所想的，那些礼物呀、花花呀什么的...！我想这个也是每个人，每个阶段对它的定义都不一样吧————更用心的去热爱生活！

天气是真的热，不知道是成都没有春天，还是说气候是真的反常了。

<LImg :imgs="xinglong2" intr="兴隆湖" />

成都难得的蓝天白云，一家人不一起露露营吗？陪孩纸嬉戏湖水，和爱人沐浴清风，仍湖面的白云随波而去，一起享受周末的惬意时光吧。

<LImg :imgs="baby" intr="我家大宝贝" />

哎呀，越看我家大宝贝越乖，爱爱爱...爱不够！当然就像她今天漫步闲聊描述的一样，喜欢的时候真的爱不释手，时时刻刻都想腻歪在一起;那不喜欢的时候真的也是想大战三百回合,这种感觉奇妙飘飘...

## 紫霞山

原计划还是准备去洛带的金龙长城，后面查看是需要收取门票30元，不知道是以前不收还是时间过久忘记了；反正我们就是觉得不划算、没必要，后面我想不能扫了大家的兴致，但是天气这么热，那么我们就去了相对来说，轻松且凉快的地方吧————龙泉紫霞山。

这地方我熟悉🙂，大学的时候就来过，回想一下居然已有十年了，我不得不承认自己成功的把自己熬成了一个‘老腊肉‘😂。不谈啦——安安静静的爬山——它不香嘛！

反正这边车就路边随便停停吧，大家都这么停呢！公交站大家都不怕，我们也不要虚啦！

<LImg :imgs="zixia1" intr="紫霞山入口人太多，下次补‘标志性‘照片" />

这边难度不大，天气也巴适得起板板，不管你是带女友，还是老人孩子都是挺合适不过的了。

<LImg :imgs="zixia2" intr="你看这小阳光，是不是你眼眸里的光" />

带小朋友来玩的家庭还是挺多的，害苦了这些下家伙，苦苦哀怨下次再也不来了。

<LImg :imgs="zixia3" intr="可惜今天能见度不够，不然我要俯瞰成都😄" />

其实就开始一段路程，相对来说是一直往上攀爬的感觉，只要你登上第一个顶点后；感受了山风的拂面、水份的清凉，就算你很少运动，后面的路都是小菜一碟。

<LImg :imgs="zixia4" intr="其实就这点路程" />

植被茂密，偶尔还有花香弥漫；我想只要不是很热的天，这地方也是挺悠闲自得的。

<LImg :imgs="zixia5" intr="怎么全是拍的上坡，不会吓退你吧" />

你看别的小朋友都可以的，不要放弃马上安排下坡；其实全程就几个起伏的小山顶而已，如果你走右侧的下山路，后面有一个不错的湖泊，简直就是钓鱼人的天堂。

<LImg :imgs="zixia6" intr="你多久没有见过这种大蚂蚁了" />

我也不知多少年没有见过这种大蚂蚁了，反正就是挺久挺久的过往；那些曾经儿时普通的记忆过往，已成为我现在难得的美好时光。

<LImg :imgs="zixia7" intr="山光湖水，美好佳人" />

有时候我也总觉得，风景也是留给有准备的人；多出去走走，只希望把所有记忆的脑海里，装满的全部都是这世间的美好。

<LImg :imgs="zixia8" intr="猜猜这是什么啥？" />

好几年没见过这玩意了，看着这熟悉货怎么突然有点可爱了呢————因为，这货是我不喜欢吃的土豆，我想跟我不喜欢土豆的人应该很少吧！

<LImg :imgs="zixia9" intr="猜猜这是什么啥？" />

不经意的拍摄，搭配在一起却又有，说不出的美好画面；我想也许是因农民伯伯，辛勤劳作后最美好的回报吧，感谢大自然的馈赠！

<LImg :imgs="zixia10" intr="我最美好的，当然是我家大宝贝啦" />

我想我的‘仪式感’也许就是给辛苦生活的一抹甘甜吧，不需要你刻意去营造，只需你用心去感受生活！
