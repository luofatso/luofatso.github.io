# 官塘新村

下午打完乒乓球，晚饭就随便弄了点凉面应付，还真别说这操作挺洒脱；也不知道怎么就突然就聊到了官塘新村，我提议说明天可以去简单看看，鬼子一个灵光——要不吃完就去；有时候就应该有这种说干就干、说走就走的劲头。

<LImg :imgs="guantang_start" width='75' intr="是洒脱的凉面呀" />

去年国庆其实我们就来过一次，只是当时乘坐的是公共交通；这次朋友开车过来导航到村里人家去了，我们绕了一圈才到游客中心，所以用‘缺德’的朋友注意导航‘官塘游客中心’。

<LImg :imgs="guantang1" width='85' intr="也是记忆里最美好的岁月静好" />

也许是因为昨晚那一场痛彻的大雨，还偷闲沉醉在酷辣辣的夏日之中；也许是因为今天恰到好处的时机，让我们遇到如此动人而静好的画面；也许本就该如此，只是我们离得太远，走得太久，才会忘记记忆里最似曾相识的美好。

<LImg :imgs="guantang2" width='85' intr="只是我们离得太远，走得太久" />

对呀！那是曾经的岁月静好。那曾经最为平常的记忆，在摇曳的晚风中记忆若隐若现——层层的稻田同田坎消失在远处的稻田里、山坡上、树荫里、晚霞中；那是消失在远处看不清的童年，仿佛又出现在眼前不远的稻田里。

<LImg :imgs="guantang3" width='75' intr="在摇曳的晚风中记忆若隐若现" />

放下手上拴着大水牛束缚的绳子，就让它对那还并未睡醒的青草上的露珠痴痴着迷；也能放飞让我好好去追捕那轻盈的蜻蜓的心吧——我用树枝轻扫水牛还来不急侵灭露珠，以免打湿裤脚回家被妈妈责备，然而最终还是打湿裤脚的我，早已记不住当时是否被责备。

<LImg :imgs="guantang4" width='75' intr="跟牛儿痴迷青草上那并未睡醒的露珠" />

本该在早上就抓住的蜻蜓，却在那个傍晚迟迟才让我给抓住；也许是因为早上那头大水牛的束缚，也许是蜻蜓也痴迷了稻田里的稻香；那时听说蜻蜓可以捕捉蚊子，能不能捕捉蚊子也并不知晓，但只知道那年有蜻蜓在蚊帐的夜晚，我睡的格外的香甜。

<LImg :imgs="guantang5" width='75' intr="跟蜻蜓也痴迷了稻田里的稻香" />

我们去年国庆来得晚了一些，那稻田里除了收割完稻桩重新发出的青苗外，就只有那湛蓝湛蓝的天空。我们想去看金灿灿的稻穗，染红整片或半边天的夕阳，和去追寻清凉的晚风、成片的蛙声，还有近处和远方的熙熙攘攘的暖灯...

<LImg :imgs="guantang6" width='75' intr="去绘画染红整片或半边天的夕阳" />

这次虽然也没全部得偿所愿，但是相比上次也好太多太多，世上那有那么多恰似刚刚好呢。去年荷叶已不记得有没有看到，但是这么好的一池荷叶映衬着小楼晚霞已是美事，来年我们一起去看荷花可好？

<LImg :imgs="guantang7" width='75' intr="和去追寻清凉的晚风" />

对了上图是现在的荒芜的田地，下图是去年当时的田园草地露天咖啡，肯定的来说当时确实有一番风情，但是对于我们来说就跟当地农民一样，却显得格格不入。荒废了也挺好，没有了那么重的商业气息，反而我倒觉得更接近风土人情一些。

<LImg :imgs="guantang8" width='75' intr="好一池荷叶衬衬托着小楼和晚霞，却早已不知是美事" />

昨夜的雨下了整整一夜，总算是褪去夏天半日酷暑，今日晚后且已还夏日半宿，夏天你可真是一个不折不扣的小气鬼呀，让我们偷得半日闲懒难道都不行了吗！

<LImg :imgs="guantang9" width='75' intr="也是，他们走的不一样的风格而已" />

这小路是我刚刚走过的小路吗？这那里是我走的路呀，这是城市里近郊农村的路，并不是真正意义上的农村的路。并不是我对农村里的路和近郊农村的路有想法，而是他们走的不一样的风格。

<LImg :imgs="guantang10" width='75' intr="阁楼的窗是为谁而开" />

暮色将近，不知是谁何时何人为何开启了阁楼的窗，我忍不住往里看是否有一个盼望着的姑娘，奈何太高却什么也瞧不见。也许是在等待，也许是故意而为之，也许是刻在骨子隐美，也许是我忘记了现在是二十一世纪。

<LImg :imgs="guantang11" width='75' intr="也许是故意而为之，也许是在等待" />

天气晚晴，暖灯初照，和夕阳完美的融合在一起，我们进去瞧一瞧是不是想象中的模样呢。

<LImg :imgs="guantang12" width='75' intr="也许是我忘却了是今昔" />

然而并不是想象中那个模样，更像没有人了的大唐盛世的夜晚，这样也挺好去掉了那份虚无的嘈杂，整个小镇也落得一下清静悠闲。也许是它累了，也许本该如此。

<LImg :imgs="guantang13" width='75' intr="让我们去掉了那份虚无的嘈杂" />

静静地感受，与享受当下的宁静吧。也许只是片刻之间，也许也能有所收获。不过也没有关系，也许还有下次相见，我相信你还有不一样的美！

<LImg :imgs="guantang14" width='75' intr="不要留恋，留恋也许只会徒增烦恼" />

多好的万家灯火啊，只可惜我呆得再久，我对于它来说，我仍然也只是一个匆匆过客。不要留恋，也许留恋只会徒增烦恼，也许也仅仅是也许！
