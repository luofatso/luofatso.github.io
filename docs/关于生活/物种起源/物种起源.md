# 物种起源

'因果循环,自有定数,万事皆有轮回；有因必有果；',我们人类总喜欢有源可溯。

我其实不是来说因果论的，更不会来说‘物种起源’的，这些'远大前程'的道理，我是‘目不可及’。

其实就是想写写，想简单的记录一下自己平凡的生活；你说我能记录自己什么呢，每天就是哪些平平凡凡的琐事，说实话我现在也不知道，反正觉得内心有种隐隐呼唤，反正就是在看在写的时候自己很平静，自己觉得很享受。

依稀记得对自己最早的流水账记录还是小学的日记，是那种‘早饭吃了就是午饭最后是晚饭‘的口水话；不是没有其他可记录，是当时笨至现在；我也为自己找过借口，说自己是为了完成任务，是不知道结构啥的。

后来上初中我们班主任刚好也是语文老师，他强制我我们每天一个日记，那怕一周有一两天‘今日没有可记’都得记录；还有就是他会在每个寒暑假都要求我们读一本名著及一本其它读物不限，那时候多少有点抱怨吧。也许就是那个时候文字在我内心隐隐的埋下了种子。虽然自己的语文也就平平，也就算个及格；但是喜欢阅读，喜欢记录平淡的生活从那以后基本就没断过。

上班前几年还阅读还记录的，但是坚持了两三年后不知道怎么就断了记录;虽然偶尔还在阅读，但是也就像漆黑的夜晚，真的很难找到几颗明亮的星星。也许是当时痛苦的生活，也许是被自己麻木了,也许是借口，迷失在沉沦中出不来...

期间多次曾想拿起那支笔，但总是被自己抛之脑后。今天没有因为为什么，没有受什么刺激，你要硬说为什么；也许是那颗沉沦的心，似尘埃，似果实，时间把他们都熬成了地板，熬成了果。
