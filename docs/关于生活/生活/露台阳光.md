# 露台阳光

你是否也渴望有一个属于自己的小菜园、小花园呢？面向大海，春暖花开眼😎！

那你又是为什么喜欢它们呢？社交还是休闲，我想不管如何，享受那份宁静自然，让灵魂乐在其中。

## 说明

此文记录一下，休闲时间在阳台种植的一点乐趣。

非专业种植，纯属娱乐，就是看着空旷的阳台的一时‘冲动’，记录一下空洞城市中的有趣灵魂😂。

开始我们是在网上买了营养土，但是总觉得这玩意不足以养殖植物；反正我们住在城乡结合部，去旁边待开发暂种植的农田搞土还是比较方便；于是乎我们就去旁边的农田，弄了两袋土回来和营养土一起使用。别说一袋看着多，但是回来混合放入泡沫箱里后，也就刚刚够。

由于时间已是去年的事情，所以搞土的照片已找不到了，小可惜。

## 培育

先买的营养土，开始种植的是长芽的蒜，但是好像没有什么意思；于是我们就买了辣椒苗和辣椒种子，双管齐下总有收获。

<LImg :imgs="plant2" intr="自己培育长出来的小辣椒苗" />

另外买的辣椒苗也回来了，还有在鬼子那里移栽的黄瓜苗。苗太小太阳太大，差点有一苗没有坚挺下来，还好每天悉心关照（中午热的时候我会搬到客厅😂），对——因为爱，它活过来了！

<LImg :imgs="plant3" intr="齐全，怎么说——完活？" />

<LImg :imgs="plant4" intr="小菜园还是小花园？" />

老实说：这还是我第一次，见仙人球开花，更别说两个同时了，整个过程还是挺短暂的；包括长这两‘ge lang’,到开花的过程也就只有3-5天的样子；盛开的时候是晚上，第二天早上也能看到，洁白无暇，有点白色荷花的感觉，但是等到下班回家就没了！

<LImg :imgs="plant5" intr="意外之喜，仙人球开花了" />
<LImg :imgs="plant6" intr="东倒西歪像什么话呢" />

## 开花啦

买的辣椒苗回来就比自己培育的大，所以最先开花花了；这玩意开花就结辣椒，好像不需要授粉是不是？有懂的吗，出来科普一下！

<LImg :imgs="plant8" intr="辣椒花" />

但是我在网上看到说，辣椒最早的第一波花，最好还是摘；好像是说让其营养先长辣椒跟株，这样的话以后的接的辣椒更多；我们也不懂，那就先试试呗！

<LImg :imgs="plant9" intr="辣椒花一张不够" />

黄瓜一样的道理，第一次的果果直接咔嚓！

<LImg :imgs="plant10" intr="黄瓜就直接开花结果了" />

<LImg :imgs="plant11" intr="有点点意思哈" />

## 驱虫

一天早上突然发现，其中有一株辣椒的心上面长了好多那种小虫虫，当时还没有在意，想着植物应该也有自己的抗疫能力。但是过了一天发现又长了好多，于是乎没有管它三七二十一，直接接拿来了蚊子药，一顿操作猛如虎——没想到下午回来虫是没了，但是辣椒植株也死了😭！

<LImg :imgs="plant12" intr="最早的辣椒" />


过了一段时间，又发现了另外几株也长虫了，这次不敢瞎玩了。先网上搜索了一下，知道了是什么虫虫——现在又忘记了，说用洗洁精和白醋可以的；这次长了点心眼，先用一株辣椒实验了一番，哎哟——有点那什么作用！
