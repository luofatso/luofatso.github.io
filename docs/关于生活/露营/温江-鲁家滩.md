# 温江-鲁家滩

<LImg :imgs="ljt1" width="55" intr="慵懒的午后没有微风，是绝对不可能的" />

朋友多次约我们一起露营，不是时间不允许，就是时间冲突，这一次我们还好终于没有放弃；有没有一种耍朋友的感觉，对了——这就是我们的朋友。

<LImg :imgs="ljt2" width="55" intr="那微风绘画的风景，在你的眼波里，在我记忆的脑海里" />

因昨天徒步大家比较累，所以选择了较近的鲁家滩湿地公园，来得比较晚人有点多，最后我们选择了河对面的绿荫小道边。

<LImg :imgs="ljt4" width="55" intr="生活的微风吹呀吹，吹到了锅里在翻滚，吹到了舌根味蕾里在跳跃，吹到了我的心里在汹涌" />

夏日午后微风也变得如此慵懒，一阵一阵的，好似打盹后没有睡醒的小孩，憨憨而又认真的样子；是可爱的，是有温度的，是舒适惬意的。
