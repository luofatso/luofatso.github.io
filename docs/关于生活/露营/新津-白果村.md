# 新津-白果村

<LImg :imgs="bgc1" width="75" intr="不要将就自己，不要敷衍生活。再忙碌，也要留一些诗意、存一些柔软。" />

阳光——以前从来不会想象到是如此的珍贵，那个时候觉得很多东西都是理所当然，现在回想起那个时候才是真正的美好，回不去的记忆才是最宝贵的。

在成都，春冬季要是有一个暖洋洋的大晴天，那各大小公园可真是人山人海，一丁点都不为过；再加上口罩过后，人们好像都更愿意出去走走了。只有你有所经历，才会懂得更多，趁着有时间、趁着年轻、趁着周末去疯狂、去露营、去享受生活。

<LImg :imgs="bgc10" width="45" intr="开始-结束-开始" />

::: tip 提示

- 日出、云海、佛光等自然奇观还是要开天气情况的，所以有想看的得提前看好天气情况。

- 一路没有补给点，食物和水一定要带充足，高山失温是件很可怕的事情，不可儿戏。
  :::

::: warning 注意

- 高山地带天气多变，要去的小伙伴一定要注意提前看好天气情况，做好防雨、防雾、防风、防晒、防滑、防寒的准备和工具。

- 铁瓦殿看着路程不是很远，但是海拔爬升还是在的，时间一定要留充足，下山带好灯具，不建议没有经验的小伙伴夜爬。
  :::
