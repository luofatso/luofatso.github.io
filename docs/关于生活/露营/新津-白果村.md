# 新津-白果村

<LImg :imgs="bgc1" width="75" intr="不要将就自己，不要敷衍生活。再忙碌，也要留一些诗意、存一些温柔..." />

阳光——以前从来不会想象到是如此的珍贵，那个时候觉得很多东西都是理所当然，现在回想起那个时候才是真正的美好，回不去的记忆也许才是最宝贵的。

<LImg :imgs="bgc2" width="45" intr="当时好多想对你说的话，留在回忆的留白中被时间无情地擦去，留下的只是一个模糊的记忆。" />

在成都，春冬但逢一个软烘烘的晴天，那么大小公园便活了过来；三年前那些捂紧口罩疾走的影子，如今都化在暖风里了。

<LImg :imgs="bgc3" width="45" intr="人生那有那么多如果，你我皆凡人，任性应当对应那个无忌的年龄。" />

原来人活一世，贪的就是这般寻常。当知阳光会过期，座位会坐满，连拥挤都是恩赏。

::: tip 注释
拖延从来不是我的借口，而是我自己证明自己的活着的有效依据。

那日的阳光像融化的蜜，把整条江都浇得亮晃晃的。春水涨得有些任性，漫过石阶时还裹着冬天未褪的暗涌——像你欲言又止时，睫毛投下的那片影。
:::
