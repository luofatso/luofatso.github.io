# 金堂-团结水库

时间像被风扯长的炊烟，两年的记忆，却依稀在我脑海中氤氤氲氲。

<LImg :imgs="tjsk1" width="55" intr="像炊烟一样的过客，嬉戏、袅袅、冉然" />

好像过了很久，好像也简简单单，好像就一直在身边，在等待；渴望而平静，温柔而零碎，淅淅淋淋——似冲撞洒满的整个山野的琳琅星火。

<LImg :imgs="tjsk2" width="55" intr="似满山摇曳的小花，似西嬉弄的湖面，一遍又一遍，萦萦...浅唱..." />

就像破旧而鲜泽的老家具，你知道，我也知道，都是你和我；那木纹——是昨天，是今天，是明天，是永远的记忆呀！

有些萦萦袅袅的往事，会一直在脑海里不刻意而又来来回回的冲刷着我们，像极了心灵的眼眸，一遍又一遍，希望你我在每一个瞬间都能够温情暖暖。
