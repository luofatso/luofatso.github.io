# 简阳-自生桥

你站在那里静静地发呆，我坐在那里静静地看你，时间好像在你我的左右擦肩而过；就像孩童攥着蜡笔，在留白处画歪了直线。

<LImg :imgs="zsq1" width="55" intr="好像在哪里见过你，你和风一样自由" />

你站在那里发呆，像一株忘了季节的植物，我坐在光的背面数你呼吸的间隙——时间从我们之间挤过去；就像孩童攥着蜡笔，在留白处画歪了直线，又固执地涂成一道彩虹。

<LImg :imgs="zsq2" width="55" intr="左，偏左，就用左手" />

你站在窗前，把自己站成一片淡去的影子，
我坐在时间里，用目光替你补完轮廓。
风从你左边来，从我右边走——
像那个画歪直线的孩子，突然搁下笔，
说：“算了，改成星星吧。”

<LImg :imgs="zsq3" width="55" intr="红的、白的、紫的、蓝的...管它什么色的，只要是你喜欢的" />

我们之间，是蜡笔划过纸的沙沙声，
是橡皮屑落在裙摆上的沉默。
时间擦肩时，你忽然眨了眨眼——
而那条歪斜的线，至今
没人舍得擦掉。

你发呆的侧脸，像一块正在融化的冰，
我数着你睫毛投下的阴影，一格一格，
直到时间从我们之间抽离——
像蜡笔突然折断，
在纸上留下一道未完成的甜味。

你站在那里静静地发呆，
我坐在那里静静地数——
数时间如何从你左肩绕过我右肩，
像孩童松开蜡笔时，
那条歪斜却不肯重画的直线。
