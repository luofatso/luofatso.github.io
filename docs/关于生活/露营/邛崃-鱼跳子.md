# 邛崃-鱼跳子

<LImg :imgs="ytz1" width="55" intr="听，是窃窃私语的流淌声" />

你告诉我你很喜欢另一个自己，我想也许它会用不同方式相同结果告诉你，谁都改变不了的结果——我们就是我们自己。

<LImg :imgs="ytz2" width="55" intr="看，是波光粼粼的碎片——" />

有时候我也会想起以往的种种，觉得那时的自己都那么的单纯；我也曾多次告诉自己：不要去想太多，当时的自己已经很了不起，也许再来一遍我们依然步履瞒珊。

你可知晓莱布尼茨的‘世上没有两片相同的叶子’？可纵使每片叶的脉络各异，但是我知道树叶不管如何的摇曳，都会静静地化作春泥以另一种方式延续自己。

<LImg :imgs="ytz4" width="55" intr="是银河失手打翻的镜子，还是风揉皱了一湖星焰？" />

说明一直以来我们自己都在成长，庆幸当时的自己莽撞却果决的选择了开始，我们又怎敢轻蔑地回望？任何东西或过程都没有无效的存在，我始终相信它不在当下，就会在将来的某个时间发挥它该有的作用。

::: tip 注释
鱼跳子环境还挺不错的，就是距离成都有点远，一天内游玩的话有点累，建议周末两天去玩。
:::
