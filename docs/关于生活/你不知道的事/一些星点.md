# 一些星光

记录自己在生活工作中的一些人生道理的启迪，或许对自己有用；

1. 做决定之前需要对整个事情做全面了解，表面、背后、基础、能提过的效果、大致自己的期望、出现纰漏的补救、对不能达到的效果的最低底线；做最好的结果和最坏的打算。
2. 做事不犹豫，扫清对自己不利的一切人和事，坚决不内耗。
3. 以事情为中心，对有纰漏之人绝不手软，对有贡献之人大举表扬及奖赏；必须快速响应，绝不能拖延。
4. 不论任何人及多热情、健谈、满意，都不能忘记事情本质，需要的流程不能少走、不走；保证自己和合作人的利益，保证以事情为中心的思想到底。
5. 做事情的流程表，让事情在自己心里有谱（胸有成竹）；把控事情的进度，及时校验（控制风险）；有效的总结及复盘。
6. 有信任的朋友和导师，任何事情总有自己的不懂不解之处；人无完人，及时请教、弥补自己的不足；让他们做你的向导、做你的导师。
7. 迷惑、不解的时候可以适当放松自己，跳出当前视角（当局者迷），做做其它事情，散散步，也许会有意想不到的收获。
8. 心态才是良好的向导，好的心态已经成功了一半；当事情折磨自己的心态的时候，应该及时跳出魔怔；当不是自己的事情看待，让子弹飞一会儿。
9. 不要去自责，不要去抱怨；路是在脚下的，生活是向前的；就算从来一次你还是你，结果还是一样的；因为你当时的认知仅当时的认知，人就是在一次一次失败，在跌倒后慢慢成长起来的。
