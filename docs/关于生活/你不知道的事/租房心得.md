# 租房心得

## 朝向

- 最好朝南，这样南北通透，良好的通风有助于身心健康；
- 是否临街、工地，一般汽车，行人会太吵，不利于睡眠；还有就是灰尘太大；
- 夜市，娱乐场所附近，学校附近，广场附近，要不是晚上睡不好，就是早睡不好；
- 市场，商超等

## 楼层

- 低层区，吵闹，麻将馆
- 高层区，酷暑，寒冷

## 厕所

- 防水
- 大小
- 地板颜色、材质

## 家电

- 门锁及小区、单元、车库门禁、钥匙、门卡、水电气卡等
- 电源保险总闸，灯光明亮是否，灯光开关是否损坏（屋内所有灯光），包括浴霸
- 水闸开关，所有水龙头是否老化漏水，包括淋浴等
- 天然气，是否民用，是否老化，灶台是否老旧、危险，火力是否
- 热水器，年代是否久远，是否老化，是否调温便捷
- 抽油烟机，是否老化，查看风力
- 微波炉，是否有
- 空调，是否制冷迅速
- 冰箱，是否老化，是否有灯，是否制冷，是否生锈等
- 洗衣机，是否老化，是否智能
- 电视，是否可用
- 宽度，是否有接口
- 门窗是否好开关、损坏等
- 床，大小，是否老旧，是否单一简单，试坐，稍微摇晃，
- 衣柜，大小，老旧，开关，
- 茶几，其它桌椅等，老旧，损坏等
- 地板，是否老旧，起壳，掉色，注意颜色（方便后期打扫）
- 墙面，是否老旧，涂写，回潮起霉，
